## 树套树-经典题目清单

### 一、 动态区间第 k 小
- **P2617 Dynamic Rankings**：单点修改，区间第 k 小。树状数组套权值线段树。$O(n \log^2 n)$。
- **P3332 [ZJOI2013] K大数查询**：区间插入数，区间第 k 大。线段树套权值线段树，标记永久化。$O(n \log^2 n)$。

### 二、 区间排名与前后驱
- **P3380 二逼平衡树 / BZOJ3196**：区间排名、第 k 小、前驱、后继、单点修改。线段树套平衡树。$O(n \log^3 n)$。

### 三、 树上带修路径第 k 大
- **P4175 [CTSC2008] Network**：树上路径第 k 大，带修改。树剖 + 树状数组套主席树，差分公式 $u+v-lca-fa(lca)$。$O(n \log^3 n)$。
- **SP16580 QTREE7**：动态树路径信息维护。LCT 套线段树/平衡树维护虚子树信息。$O(n \log^2 n)$。

### 四、 动态逆序对
- **P3157 [CQOI2011] 动态逆序对**：删除元素，求逆序对。树状数组套权值线段树（在线）或 CDQ 分治（离线）。$O(n \log^2 n)$。
- **P3759 [TJOI2017] 不勤劳的图书管理员**：带权动态逆序对 + 交换。树状数组套主席树。$O(n \log^2 n)$。

### 五、 三维偏序
- **P3810 陌上花开**：三维偏序。按 $a$ 排序，树状数组套权值线段树维护 $b,c$（在线）；或 CDQ 分治（离线）。$O(n \log^2 n)$。
- **P4093 [HEOI2016/TJOI2016] 序列**：带修最长不下降子序列。转化为三维偏序，树状数组套权值线段树维护 DP。$O(n \log^2 n)$。

### 六、 二维矩阵操作
- **P4915 帕秋莉的魔导书**：矩形加，矩形求和。线段树套线段树（动态开点防 MLE）。$O(n \log^2 n)$。
- **P4088 [USACO18FEB] Slingshot**：二维矩形最值。绝对值分类讨论转二维数点，树套树或扫描线（128MB 卡空间）。$O(n \log^2 n)$。
- **P4514 上帝造题的七分钟**：矩形加，矩形求和。二维树状数组或线段树套线段树。$O(n \log^2 n)$。

### 七、 带插入的动态区间第 k 小
- **P4278 / BZOJ3065 带插入区间K小值**：带插入与修改的区间第 k 小。块状链表 + 值域分块（正解）或替罪羊树套线段树。$O(n \sqrt n \log n)$ 或 $O(n \log^2 n)$。

### 八、 动态图连通性
- **P5247 动态图完全连通性**：动态图连通性模板。线段树分治 + 可撤销并查集（按秩合并，不路径压缩）。$O(n \log^2 n)$。
- **P4246 [SHOI2008] 堵塞的交通**：2行n列网格连通性。线段树分治 + 可撤销并查集。$O(n \log n)$。

### 九、 其他特色题
- **P5445 [APIO2019] 路灯**：动态维护连通块历史信息。树套树 + 扫描线（在线）或 CDQ 分治 + 扫描线。$O(n \log^2 n)$。
- **CF 1093E Intersection of Permutations**：两排列交集大小，支持交换。树状数组套主席树或套 pb_ds。$O(n \log^2 n)$。
- **CF 1436E Complicated Computations**：子区间 mex 的 mex。树套树或主席树维护位置，二分判断。$O(n \log^2 n)$。
- **CF 1422F Boring Queries**：强制在线区间 LCM。树套树或主席树维护质因子。$O(n \log^2 n)$。
- **CF 19D Points**：二维平面插入删除，查询右上方点。线段树套 set，离散化 x 坐标。$O(n \log^2 n)$。

## 集合操作-经典题目清单

### 一、 集合合并
- **P3224 [HNOI2012] 永无乡**：加边，连通块第 k 小。并查集 + 权值线段树合并。$O(n \log n)$。
- **P4556 雨天的尾巴**：路径发粮，求每点数量最多的类型。树上差分 + 权值线段树合并。$O(n \log n)$。
- **CF 600E Lomsat gelral**：子树众数颜色编号和。DSU on Tree。$O(n \log n)$。
- **P3521 [POI2011] ROT-Tree Rotations**：交换左右子树，最小化先序逆序对。权值线段树合并，合并时统计逆序对。$O(n \log n)$。

### 二、 集合插入/删除/查询
- **P2617 Dynamic Rankings**：单点修改，区间第 k 小。树状数组套权值线段树（删除旧值 + 插入新值）。$O(n \log^2 n)$。
- **P3380 二逼平衡树**：区间排名、第 k 小、前驱、后继。线段树套平衡树。$O(n \log^3 n)$。

### 三、 集合交并差
- **CF 1093E Intersection of Permutations**：两排列区间交集大小。树状数组套主席树，映射位置转二维数点。$O(n \log^2 n)$。
- **P5283 [十二省联考 2019] 异或粽子**：区间异或和的前 k 大。可持久化 01-Trie + 优先队列。$O(n \log V \log k)$。
- **高维偏序 bitset 暴力**：集合交并大小。`std::bitset` 按位与/或。$O(n^2 / 64)$。

### 四、 集合 mex / 区间众数
- **CF 1436E Complicated Computations**：子区间 mex 的 mex。树套树/主席树维护值出现位置，二分判断。$O(n \log^2 n)$。
- **P4168 [Violet] 蒲公英**：静态区间众数，强制在线。分块预处理块区间众数与出现次数。$O(n \sqrt n)$。

### 五、 集合拆分与合并
- **P5494 线段树分裂**：多重集插入、删除、分裂、合并、第 k 小、区间和。动态开点权值线段树分裂+合并。均摊 $O(n \log n)$。
- **BZOJ 4552 / P2824 [TJOI2016] 排序**：区间升降序排序。线段树分裂+合并，或二分答案+线段树。$O(n \log n)$。
