## 线段树-用法

### 一、 基础架构
- **静态堆式**：数组大小 4n，`p*2` 与 `p*2+1` 访问子节点。适用于数据量已知。
- **动态开点**：不预建全树，用到才开。空间 $O(k \log V)$，用于值域极大或稀疏场景（如 $[1, 10^9]$）。
- **zkw线段树**：自底向上非递归，常数极小。适合可差分信息（如区间求和、异或和）。

### 二、 按维护信息分类
- **可差分信息**：区间和、区间异或和。可用树状数组替代。
- **不可差分信息**：区间最大/最小值、区间 GCD。
- **复合信息**：如最大子段和，节点需维护 `sum`、`max_prefix`、`max_suffix`、`max_subarray`。
- **势能信息**：区间取模、区间开方。值快速收敛，维护最大值判断是否需递归。

### 三、 按维护操作分类（Lazy Tag 体系）
- **区间加/乘/赋值**：乘法优先于加法，赋值可覆盖所有。下传顺序：乘 -> 加 -> 赋值。
- **区间翻转**：用于维护序列或字符串，需同时维护正反信息，配合 `rev` 标记。
- **区间取 min / max (Segment Tree Beats)**：维护最大值 `mx`、次大值 `se`、最大值个数 `cnt`。均摊复杂度 $O(n \log n)$。
- **区间历史最值**：维护历史最大值/最小值，需记录历史最大增量。
- **标记永久化**：不写 `pushdown`。查询时累加沿途标记贡献。用于可持久化、树套树。

### 四、 按区间处理分类

- **区间合并**：查询返回结构体，将多个子区间答案合并（如最大子段和）。
- **线段树上二分**：$O(\log n)$ 找前缀和 $\ge k$ 的位置。从根节点判断左子树是否满足，否则递归右子树。
- **坐标离散化**：坐标范围大但有效点少时，先离散化再建树。

### 五、 进阶结构与变体

- **可持久化线段树（主席树）**：每次修改新建 $O(\log n)$ 节点，保留历史版本。求区间第 $k$ 小，用两棵线段树相减。
- **线段树合并**：均摊 $O(n \log n)$，常用于树上信息合并（替代 DSU on Tree）。
- **线段树分裂**：按前 $k$ 个元素拆树，复杂度 $O(\log n)$。
- **李超线段树**：维护二维平面线段/直线，支持插入与查询最值。用于斜率优化 DP。
- **树套树**：线段树套线段树/平衡树，解决高维问题。
- **线段树优化建图**：节点代表区间，单点连区间、区间连单点用虚拟节点，边数降为 $O(n \log n)$。
- **扫描线**：矩形面积并/周长并。按 $x$ 排序，线段树维护 $y$ 轴覆盖长度。
- **动态 DP (DDP)**：树链剖分 + 线段树维护转移矩阵，解决带修改的树上 DP。
- **全局平衡二叉树**：用于树剖，解决 LCT 常数大、树剖 $O(\log^2)$ 的问题。DDP 的终极优化。

### 六、 线段树分治

- **适用场景**：操作只在某段时间内有效（如动态图连通性、带删除的背包）。
- **核心思想**：以时间轴建立线段树，将操作映射到时间区间上。DFS遍历这棵树，进入节点时应用操作，离开节点时撤销操作（需要支持撤销的数据结构，如可撤销并查集）。
- **具体步骤**：
  1. 将操作的时间区间 $[l, r]$ 打上懒标记，添加到时间线段树中。
  2. 从根节点开始 DFS，每到一个节点，应用该节点的所有操作。
  3. 到达叶子节点时，统计当前时间点的答案。
  4. 回溯时，撤销当前节点的所有操作（需要可撤销数据结构支持）。
- **复杂度**：$O(n \log n \cdot T_{apply/undo})$。若使用可撤销并查集，总复杂度 $O(n \log n)$。
- **配套数据结构**：可撤销并查集（按秩合并，不能路径压缩）。

### 七、 其他高级技巧

### 猫树 (Cat Tree)

- **定义**：一种基于分治的静态区间查询数据结构，不支持修改。
- **核心思想**：对于每个分治节点区间 $[l, r]$，令 $mid = \lfloor \frac{l+r}{2} \rfloor$。预处理左半区间所有点到 $mid$ 的信息合并结果（后缀），以及右半区间所有点到 $mid+1$ 的信息合并结果（前缀）。
- **查询逻辑**：
  - 若查询区间 $[ql, qr]$ 跨过 $mid$（即 $ql \le mid < qr$），答案直接由 $ql$ 的后缀信息和 $qr$ 的前缀信息合并得到。
  - 若 $qr \le mid$，递归左子树；若 $ql > mid$，递归右子树。
- **$O(1)$ 查询原理**：
  - 预处理时，记录每个下标对应的 $O(\log n)$ 层信息。
  - 查询时，求 $ql$ 和 $qr$ 在二进制下的 LCP（最长公共前缀），直接定位到它们的分治节点，无需递归。
- **索引下标说明**：
  - 建树时，叶子节点对应完全二叉树的底层，将数组下标 $i$ 映射为叶子编号 $x = i + N - 1$（$N$ 为大于等于 $n$ 的最小 2 的幂）。
  - 分治节点编号若为 $p$，其管辖的左子树和右子树分别为 $p \times 2$ 和 $p \times 2 + 1$。
  - 内部节点存储的信息 `f[dep][i]` 中，`dep` 表示节点所在的深度（根为 0，叶子为 $\log N$），`i` 为原数组下标。
- **LCP 求法**：
  - 对于查询区间 $[ql, qr]$（0-indexed），它们对应完全二叉树叶子编号 $x = ql + N$，$y = qr + N$。
  - 计算 `x ^ y`，利用 `__builtin_clz(x ^ y)` 求前导零个数，即可得到它们 LCA 的深度 `dep = __builtin_clz(x ^ y)`（假设 32 位整数，深度为 $31 - \text{clz}$）。
  - 在此深度下，$ql$ 和 $qr$ 必然位于同一个分治节点的左右两侧（即 $ql$ 在左，$qr$ 在右）。
  - **最终答案**：直接合并 `f[dep][ql]` 和 `f[dep][qr]` 即可。
- **建树细节**：
  - 维护二维数组 `f[dep][i]`，表示第 `dep` 层，下标 $i$ 对应的信息。
  - 从 $mid$ 向左遍历合并信息，从 $mid+1$ 向右遍历合并信息。
  - 递归构建左右子树。
- **复杂度**：
  - 预处理：$O(n \log n)$。
  - 查询：$O(1)$。
  - 空间：$O(n \log n)$。
- **适用场景**：静态、不可差分信息、查询次数极多、要求常数极小。
- **典型应用**：区间最大子段和、区间 GCD、区间最大值。
- **与线段树对比**：线段树查询 $O(\log n)$，支持修改；猫树查询 $O(1)$，不支持修改，空间较大。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 1e5 + 5;
const int LOG = 18; // 2^17 = 131072, 足以覆盖 1e5

struct Node {
    int sum, mx, lmx, rmx;
    // 默认空节点，用于合并
    Node() { sum = 0; mx = lmx = rmx = -1e9; }
    Node(int v) { sum = mx = lmx = rmx = v; }
};

// 合并两个节点信息
Node merge(Node a, Node b) {
    if (a.mx == -1e9) return b;
    if (b.mx == -1e9) return a;
    Node res;
    res.sum = a.sum + b.sum;
    res.lmx = max(a.lmx, a.sum + b.lmx);
    res.rmx = max(b.rmx, b.sum + a.rmx);
    res.mx = max({a.mx, b.mx, a.rmx + b.lmx});
    return res;
}

int N; // N 为大于等于 n 的最小 2 的幂
int a[MAXN]; // 1-indexed 原数组
Node f[LOG][MAXN << 1]; // f[dep][i] 存储节点区间内 i 到 mid 或 mid+1 到 i 的合并信息

// 建树：递归构建，dep 表示当前深度（根节点从 0 开始）
void build(int l, int r, int dep) {
    if (l == r) {
        f[dep][l] = Node(a[l]);
        return;
    }
    int mid = (l + r) >> 1;
    
    // 左半区间 [l, mid]：从 mid 向左合并（后缀）
    f[dep][mid] = Node(a[mid]);
    for (int i = mid - 1; i >= l; i--) {
        f[dep][i] = merge(Node(a[i]), f[dep][i + 1]);
    }
    
    // 右半区间 [mid+1, r]：从 mid+1 向右合并（前缀）
    f[dep][mid + 1] = Node(a[mid + 1]);
    for (int i = mid + 2; i <= r; i++) {
        f[dep][i] = merge(f[dep][i - 1], Node(a[i]));
    }
    
    build(l, mid, dep + 1);
    build(mid + 1, r, dep + 1);
}

// 查询区间 [l, r]
Node query(int l, int r) {
    if (l == r) return Node(a[l]); // 特判单点，防止 clz 未定义行为
    
    // 叶子节点映射（N 是 2 的幂，叶子节点编号从 N 到 2N-1）
    int x = l + N - 1;
    int y = r + N - 1;
    
    // LCP 求深度：x ^ y 的前导零个数
    // 32 位整数下，深度 dep = 31 - __builtin_clz(x ^ y)
    int dep = 31 - __builtin_clz(x ^ y);
    
    // 返回左区间的后缀信息 与 右区间的前缀信息 的合并
    return merge(f[dep][l], f[dep][r]);
}

int main() {
    int n, q;
    cin >> n >> q;
    for (int i = 1; i <= n; i++) cin >> a[i];
    
    // 初始化 N 为大于等于 n 的最小 2 的幂
    N = 1;
    while (N < n) N <<= 1;
    
    build(1, n, 0);
    
    while (q--) {
        int l, r;
        cin >> l >> r;
        cout << query(l, r).mx << "\n";
    }
}
```
