## mex-结论

### 一、 基础性质
- **定义**：$mex(S)$ 为最小的不属于 $S$ 的非负整数。
- **上界**：$mex(S) \le |S|$。值域 $[0, n]$ 时 $mex \le n$。
- **单调性**：集合加元素，$mex$ 单调不减；删元素，单调不增。
- **区间性质**：值 $v$ 未出现，则 $mex \le v$。
- **集合意义**：$mex(S) = k \iff \{0 \dots k-1\} \subseteq S$ 且 $k \notin S$。

### 二、 静态区间 mex
- **离线**：按 $r$ 排序，维护 `last[x]`。线段树维护 `min(last)`，二分找第一个 `last[x] < l`。$O(n \log n)$。
  `if (minv[ls] < ql) query(ls, l, mid, ql); else query(rs, mid+1, r, ql);`
- **在线**：主席树 `root[r]` 维护 `last`，二分左子树 `min < l` 则向左，否则向右。$O(n \log n)$。
- **莫队 + 值域分块**：维护 `cnt[x]` 与块内不同数个数。插入删除 $O(1)$，查询 $O(\sqrt n)$。
- **其他**：前缀 mex 预处理；HDU 4747（线段树维护每个位置的 mex，删数时更新受影响区间）。

### 三、 动态区间 mex
- **树状数组套权值线段树**：外层位置，内层 `last`。$O(n \log^2 n)$。
- **带修莫队 + 值域分块**：增加时间轴 `(l, r, t)`。$O(n^{5/3})$。
- **分块套树状数组**：强制在线，常数更小。

### 四、 树上 mex
- **子树 mex**：DSU on Tree（$O(n \log n)$）；线段树合并（合并时二分找第一个 `cnt=0`）。
- **路径 mex**：树上莫队 + 值域分块；树剖 + 树套树（$O(n \log^3 n)$）。
- **CF 1740H**：DDP 思想，权值线段树维护重链合并 mex 信息。
- **连通块 mex**：DSU on Tree 或线段树合并维护。

### 五、 贡献差分（核心）
- **套路**：枚举 mex 值 $x$，双指针求极大区间，差分标记贡献，前缀和求答案。
- **双指针**：固定 $l$，扩展 $r$ 至 $[l, r]$ 含完整 $0 \sim x-1$ 且不含 $x$。$r$ 单调不减，$O(n)$ 求所有极大区间。
- **贡献公式**：极大区间 $[l, r]$ 对询问 $[L, R]$（$L \le l, R \ge r$）有贡献。
- **差分操作**：`diff[L]++, diff[R+1]--`，对 `diff` 求前缀和即答案。
- **例题**：
  - **CF 2084E**：全区间 mex 之和。枚举 $x$ + 双指针 + 差分。$O(n)$。
  - **CF 2123E**：删除 $k$ 个数后 mex 为 $i$ 的方案数。将 $i$ 转化为 $k$ 的区间，差分 + 前缀和。
  - **GYM 102412J**：划分序列最大化贡献。线段树维护凸包，均摊 mex。

### 六、 SG 函数
- $SG(u) = mex(\{SG(v) \mid u \to v\})$。
- $SG(u) = 0 \iff$ 必败态。

### 七、 特殊模型与例题

- **CF 1436E Complicated Computations**
  - **题意**：给定长度为 $n$ 的序列 $a$，求其所有子区间的 $mex$ 值组成的集合的 $mex$。即先求出每个子区间的 $mex$，得到一个新的集合 $S$，再求 $S$ 的 $mex$。
  - **思路**：枚举可能的 $mex$ 值 $x$（从 $1$ 到 $n+1$）。对于固定的 $x$，检查是否存在一个子区间，它包含完整的 $0 \sim x-1$，但不包含 $x$。将序列按 $x$ 出现的位置进行分割，对于每两个相邻的 $x$ 之间的区间，用线段树维护值 $v$ 最后出现的位置，查询该区间内 $0 \sim x-1$ 是否都出现过（即区间内每个值的最后出现位置是否都 $\ge l$）。如果存在一个分割区间不满足条件，则 $x$ 可以作为某个子区间的 $mex$。最后在所有可行的 $x$ 中找最小的未出现值即为答案。
  - **复杂度**：$O(n \log n)$。

- **P4137 Rmq Problem / mex**
  - **题意**：给定长度为 $n$ 的序列，$m$ 次询问，每次询问区间 $[l, r]$ 内最小的未出现的自然数。
  - **思路**：**离线做法**：将所有询问按右端点 $r$ 从小到大排序。从左到右扫描序列，用线段树维护每个值最后一次出现的位置 `last[x]`。对于当前询问 $[l, r]$，在线段树上二分查找第一个 `last[x] < l` 的值 $x$，该 $x$ 即为答案。**在线做法**：使用可持久化权值线段树，`root[r]` 维护 $[1, r]$ 中每个值最后出现的位置，查询时在 `root[r]` 上二分。**莫队做法**：普通莫队 + 值域分块，维护 `cnt[x]` 和块内不同数个数，查询时找第一个不满的块。
  - **复杂度**：离线 $O(n \log n)$；在线 $O(n \log n)$ 预处理，$O(\log n)$ 查询；莫队 $O(n \sqrt n)$。

- **P6852 Mex**
  - **题意**：有一个 $0$ 到 $n$ 的排列（下标从 $0$ 开始），给出 $m$ 条信息，每条信息形如 $(l, r, val)$，表示区间 $[l, r]$ 的 $mex$ 值为 $val$。构造一个满足所有条件的排列，或判断无解。
  - **思路**：核心观察：随着 $val$ 增大，必须出现的区间不变或不断扩展。对于每个 $val$，区间 $[l, r]$ 必须包含 $0 \sim val-1$，且不能包含 $val$。可以先处理所有限制，确定每个值可能出现的区间。然后从小到大枚举值，用 `lower_bound` 找到第一个可以填入的位置，同时检查是否与已确定的位置冲突。若无法填入则无解。
  - **复杂度**：$O(n \log n)$。

- **CF 940F Machine Learning**
  - **题意**：给定序列，支持两种操作：1. 查询区间 $[l, r]$ 内所有数出现次数的 $mex$；2. 单点修改。
  - **思路**：**带修莫队 + 值域分块**。由于 $mex$ 的大小不会超过 $\sqrt n$，可以暴力枚举。用带修莫队维护 `cnt[x]`（值 $x$ 的出现次数）和 `sz[c]`（出现次数为 $c$ 的值有多少个）。查询时从小到大枚举 $c$，找到第一个 `sz[c] == 0` 的 $c$ 即为答案。
  - **复杂度**：$O(n^{5/3})$。

- **BZOJ 4129 Haruna's Breakfast**
  - **题意**：树上带修改的 $mex$ 查询。给定一棵树，每个节点有权值，支持修改节点权值和查询树上路径的 $mex$。
  - **思路**：**树上带修莫队 + 值域分块**。将树转化为欧拉序，利用树上莫队处理路径查询，同时增加时间轴处理修改。维护 `cnt[x]` 和值域分块信息，查询时找第一个不满的块，块内暴力查找 $mex$。
  - **复杂度**：$O(n^{5/3})$。

- **P5631 最小mex生成树**
  - **题意**：给定 $n$ 个点 $m$ 条边的无向连通图，边有边权。求一棵生成树，使得其边权集合的 $mex$ 尽可能小。
  - **思路**：**线段树分治 + 可撤销并查集**。枚举答案 $x$，将所有边权不在 $[0, x-1] \cup [x+1, \infty]$ 范围内的边加入图中，判断是否能构成生成树。用线段树分治处理边权区间，递归时加入边，回溯时用可撤销并查集撤销。
  - **复杂度**：$O(n \log n \log m)$。

- **P10169 [DTCPC 2024] mex,min,max**
  - **题意**：给定序列 $a$ 和常数 $k$，求有多少个子区间 $[l, r]$ 满足 $\operatorname{mex} + \min + k \ge \max$。
  - **思路**：**套路组合**。对右端点扫描线，用可持久化线段树记录每个数最后一次出现的位置，查询时线段树二分找到第一个上次出现位置 $< l$ 的值（即区间 $mex$）。同时用单调栈维护区间 $\min$ 和 $\max$ 的变化，结合线段树统计满足条件的区间数量。
  - **复杂度**：$O(n \log n)$。

- **LeetCode 2003. 每棵子树内缺失的最小基因值**
  - **题意**：给定一棵树，每个节点有基因值。对于每个节点，求其子树内缺失的最小基因值。
  - **思路**：转化为区间 $mex$ 问题。将树转化为 DFS 序，每棵子树对应一个连续区间。用线段树或主席树维护区间内每个值最后出现的位置，二分查找第一个未出现的值。
  - **复杂度**：$O(n \log n)$。

- **CF 1608F MEX counting**
  - **题意**：计数满足给定 $mex$ 约束的序列。给定 $n$ 和数组 $b$，要求构造长度为 $n$ 的序列 $a$，使得对于所有前缀，$|mex(a[1..i]) - b_i| \le k$。
  - **思路**：**贡献延迟计算 + 组合计数**。在 DP 过程中，先确定当前位置的值，但将某些贡献（如某个值是否已经出现）延迟到后续位置计算。结合组合数学统计方案数。
  - **复杂度**：$O(n^2)$。

### 八、 实现技巧
- **set 维护未出现数**：插入删 `set`，查询首元素。
- **01 序列全局 mex**：线段树维护 `min(cnt)`，左子树为 0 则向左，否则向右。
- **值域分块**：$O(1)$ 修改，$O(\sqrt n)$ 查询 mex。
- **二进制分组**：动态加点，合并多个静态结构。
- **回滚技巧**：只插不删，栈记录修改回滚。
- **贡献延迟计算**：计数类问题，先定当前位置值，贡献延迟到后续计算。
