## 树论-结论

### 重心

- 定义
  - 删去该点后最大连通块大小最小。最大子树大小 $\le \frac{n}{2}$；
- 性质：距离和最小点（可谓 **树上中位数**）
  - 所有点到重心距离和最小；
- 性质：合并性
  - 两树合并重心在连接两树 **重心的路径** 上。
- 求法
  - 见 **点分治** 代码 写烂了

#### 补充

- 带权重心
  - 每个点有权值 $w_i$，求 $\sum w_i \cdot dist(u, i)$ 最小的点。
  - 与普通重心不同，它只能靠树形 DP 或带权点分治求解。

---

### 直径

- 性质：必有一个最远点（引申为 **最小可达半径**）
  - 任意点的最远点必为直径的一个端点。
- 性质：合并性
  - 两棵树合并，新直径端点必在原来两棵树直径的 4 个端点中产生。
- 求法
  - 非负权树：两次 DFS/BFS。
  - 带负权边：树形 DP，`dp[u][0]` 记录向下最长路，`dp[u][1]` 记录向下次长路，`ans = max(dp[u][0] + dp[u][1])`。

---

### 中心

- 定义：（引申为 **直径的中点**）
  - 到其他点最大距离最小的点。
  - 一定在直径上。
- 性质：（神鬼二相性）
  - 直径长度为偶数时，中心唯一；
  - 直径为奇数时，中心为中间边的两个端点。
- 求法
  - 求出直径路径，取中点。（需要 check）
  - 树形 DP 求出每个点的最远距离 `max(dp[u][0], up[u])`，取最小值。

### LCA

#### 两点 LCA 求法

- 纯 ST 表倍增 （人上人）
  - $O(n \log n)$ 预处理
  - $O(\log n)$ 查询
  - 优点
    - 可以维护动态加叶
- DFS序 / 欧拉序 + ST 表 （夯爆了）
  - $O(n \log n)$ 预处理
  - $O(1)$ 查询
  - 缺点
    - 不能动态加叶
- Tarjan 离线 （NPC）
  - $O(n + q)$ 离线
  - 缺点
    - 并查集实现，仅限离线且查询已知的情况。
- 树链剖分 （夯爆了）
  - $O(n)$ 预处理
  - $O(\log n)$ 查询
  - 优点
    - 常数极小，常与树剖的其他操作一并使用。
- LCT （人上人）
  - $O(\log n)$ 查询
  - 优点
    - 可以指定 任意点 为 根
  - 缺点
    - 常熟大

#### 多点 LCA 求法

- 内容
    - $lca(v_1, \dots, v_k) = lca(v_{min\_dfn}, v_{max\_dfn})$。
  - 其实这个结论显然可以通过 Euler 序 / dfs 序 求 lca 推出
- 点集到 LCA 的距离和 （废话）
  - $\sum_{i=1}^k dist(v_i, lca) = \sum depth[v_i] - k \cdot depth[lca]$。
- 应用于 虚树
  - 利用多点 LCA 性质，关键点按 `tin` 排序后，相邻两点求 LCA 加入集合，即可在 $O(k \log k)$ 内建成虚树。
- PS：
  - 服了，2026 东北四省赛 F 就是这个结论
  - 所以，初始化 $O(n)$ 建立平衡树，牛逼！！！

### DFS 序

- **定义**：节点第一次被访问的时间戳 $tin[u]$。
- **子树区间**：子树在 DFS 序中对应连续区间 $[tin[u], tout[u]]$。
- **大小关系**：$tin[u] + sz[u] - 1 = tout[u]$。
- **祖先判定**：$u$ 是 $v$ 的祖先 $\iff tin[u] \le tin[v] \le tout[u]$。
- **LCA 性质**：$u$ 和 $v$ 的 LCA 是它们的公共祖先中**深度最小的父亲**。
- **应用**：
  - 不管上还是下，只要是 子树 / 链 就可以 树剖 + 线段树
    - （上 -> 下）子树修改/查询：转化为区间操作（配合线段树/树状数组）。
    - （下 -> 上）单点修改/查询（树上差分）：路径修改转化为单点修改，按 $tin$ 逆序累加。
  - 虚树构建
    - 关键点按 $tin$ 排序，单调栈维护右链。

---

### Euler 序 / 括号序

- 定义
  - 进入节点和回溯节点均记录一次，序列长度为 $2n-1$。
- LCA 性质
  - $u$ 和 $v$ 的 LCA 是 Euler 序中 $u$ 和 $v$ 第一次出现位置之间深度最小的节点。
- 括号序性质 （废话）
  - 若在进入时标记 $+1$，回溯时标记 $-1$，则前缀和为深度。
- 应用 （）
  - $O(1)$ LCA。
  - 树上莫队：
    - 将树上路径查询转化为序列区间查询
    - （注意特判 LCA 是否包含在内！！！）

---

### Prufer 序列与 Cayley 公式

- Cayley 公式
  - $n$ 个节点的完全图生成树数量为 $n^{n-2}$。
- Prufer 序列
  - 树与长度为 $n-2$ 的序列双射。
- Prufer 性质
  - 节点 $i$ 出现次数等于 $deg(i) - 1$。
- **度限制** 生成树计数 （没见过唉）
  - 已知每个点度数 $d_i$，方案数为 $\frac{(n-2)!}{\prod_{i=1}^n (d_i - 1)!}$。

---

### 虚树 (Virtual Tree)

- 做法
  - 按 DFS 序排序，相邻点求 LCA 加入集合，单调栈维护右链连边。
  - 复杂度 $O(k \log k)$。
- 性质
  - 关键点集大小为 $k$ 时，虚树总点数不超过 $2k$。

---

### 换根 DP

- 套路
  - 第一次 DFS 自底向上求子树信息 `down[u]`；
  - 第二次 DFS 自顶向下求全局信息 `up[v] = up[u] + down[u] - (down[v] + sz[v]) + (n - sz[v])`。

---

### 基环树

- 定义
  - $n$ 点 $n$ 条边的连通图。
- 套路
  - 拓扑排序 或 Tarjan 找环。
  - 断环成树
  - 对环上每个点的子树跑树形 DP
  - 最后在环上做环形 DP（或单调队列优化）。

### 树上启发式合并 (DSU on Tree)

- 套路 （原来我真的不会啊）
  - **前提**：一个节点作为轻儿子被遍历的次数 = 它向上跳轻边的次数。
  - **然后呢？** 因为每次跳轻边，子树大小至少减半（重儿子是最大的儿子）。
  - **结论**：任意节点最多被遍历 $O(\log n)$ 次。所有节点加起来，总复杂度 $O(n \log n)$。
  - **所以**：我们才敢“暴力”把轻儿子子树合并到重儿子上，因为总共暴力遍历的次数只有 $O(n \log n)$。

- 通法
  - 剖分 **重儿子** 
  - 递归 **轻儿子** 计算答案 并 **清除影响**
  - 递归 **重儿子** 计算答案 并 **保留影响**
  - 暴力合并 **轻儿子子树** 至 **重儿子**

- 看了这个说法，我怎么突然觉得：
  - 树上启发式，是 **另一种形式的莫队** 啊
  - 你看嘛
    - 都是借助已有的计算基础，
    - 借助求解顺序的先后，
    - 回答下一个询问
  - 和 树上莫队 对比
    - **树上莫队** 是 $O(n^2)$ 种 路径查询 $O(n\sqrt{n})$
    - **树上启发式** 是 $O(n)$ 种 子树查询 $O(n\log{n})$

> 居然，在算法竞赛圈，有一句著名的暴论：“莫队就是序列上的树上启发式，树上启发式就是树上的莫队。”

- 例题
  ```cpp
  // 全局变量：cnt[x] 维护颜色 x 的出现次数，ans[u] 记录子树 u 的答案
  int cnt[N], ans[N], max_cnt;
  
  // 把 u 的子树全加进去 / 全删掉
  void add_subtree(int u, int fa, int val) {
      cnt[color[u]] += val;
      if (val == 1 && cnt[color[u]] > max_cnt) max_cnt = cnt[color[u]]; // 更新答案
      for (int v : g[u]) if (v != fa) add_subtree(v, u, val);
  }
  
  void dfs(int u, int fa, bool keep) {
      // 1. 递归轻儿子，清除影响
      for (int v : g[u]) 
          if (v != fa && v != son[u]) dfs(v, u, 0);
      
      // 2. 递归重儿子，保留影响
      if (son[u]) dfs(son[u], u, 1);
      
      // 3. 暴力合并轻儿子到重儿子
      for (int v : g[u]) 
          if (v != fa && v != son[u]) add_subtree(v, u, 1);
      
      // 把当前节点 u 自己加进去
      cnt[color[u]]++;
      if (cnt[color[u]] > max_cnt) max_cnt = cnt[color[u]];
      
      ans[u] = max_cnt; // 记录当前节点答案
      
      // 4. 如果是轻儿子，清除整棵子树的影响
      if (!keep) {
          add_subtree(u, fa, -1);
          max_cnt = 0; // 答案也要重置（具体看题目要求）
      }
  }
  ```

### 长链剖分（优化以深度为下标的 DP）

- 定义
  - 剖分时选择**子树高度最大**的儿子作为重儿子（而不是子树大小最大的重儿子）。
- 性质
  - 任意节点向上跳轻边的次数为 $O(\sqrt n)$，但**总长链长度为 $O(n)$**。每条长链互不相交。
- 用法
  - 优化形如 `dp[u][dep]`（以深度为下标）的树形 DP。
  - 利用指针偏移（`f[son] = f[u] + 1`），实现 $O(1)$ 继承重儿子的 DP 数组。（onp）
  - 合并轻儿子时，暴力合并，因为每条长链只会被合并一次。
- 复杂度
  - 总时间 $O(n)$ !!!
  - 空间 $O(n)$ !!!
- **与 DSU on Tree 对比**：
  - DSU 优化**子树信息**（只关心子树整体，不关心深度）。
  - 长链剖分优化**深度信息**（必须同时关心子树和深度下标）。

- 例题 CF1009F
  - 通过代码，我可以看出来，
  - 这是求每一个子树，拥有最多节点数的层
  ```cpp
  #include <bits/stdc++.h>
  using namespace std;
  
  const int N = 1e6 + 5;
  
  int n;
  vector<int> g[N];
  int son[N], len[N], ans[N];
  int buf[N], *cur = buf;   // 内存池
  int *dp[N];               // 指针数组
  
  // 第一次 DFS：求长儿子和长链长度
  void dfs1(int u, int fa) {
      len[u] = 1;
      for (int v : g[u]) {
          if (v == fa) continue;
          dfs1(v, u);
          if (len[v] + 1 > len[u]) {
              len[u] = len[v] + 1;
              son[u] = v;
          }
      }
  }
  
  // 第二次 DFS：DP 转移
  void dfs2(int u, int fa) {
      dp[u] = cur++;                    // 分配一个槽位
      if (son[u]) {
          dfs2(son[u], u);              // 先递归长儿子
          ans[u] = ans[son[u]] + 1;     // 继承长儿子的答案（深度 +1）
      } else {
          ans[u] = 0;                   // 叶子节点
      }
      dp[u][0] = 1;                     // 自己深度为 0
  
      // 暴力合并轻儿子
      for (int v : g[u]) {
          if (v == fa || v == son[u]) continue;
          dfs2(v, u);
          for (int d = 1; d <= len[v]; d++) {
              dp[u][d] += dp[v][d - 1];
              // 维护答案：计数更大，或计数相同但深度更小
              if (dp[u][d] > dp[u][ans[u]] || 
                  (dp[u][d] == dp[u][ans[u]] && d < ans[u])) {
                  ans[u] = d;
              }
          }
      }
      // 最终检查：如果深度 0 的计数更大，更新
      if (dp[u][0] >= dp[u][ans[u]]) ans[u] = 0;
  }
  
  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      cin >> n;
      for (int i = 1, u, v; i < n; i++) {
          cin >> u >> v;
          g[u].push_back(v);
          g[v].push_back(u);
      }
      dfs1(1, 0);
      dfs2(1, 0);
      for (int i = 1; i <= n; i++) cout << ans[i] << "\n";
      return 0;
  }
  ```


- 还能 $O(1)$ 求 k 级祖先！
  - **结论**：长链剖分可以在 $O(n \log n)$ 预处理后，$O(1)$ 查询任意节点的 $k$ 级祖先。
  - **做法**：
    1. 长链剖分，对每条长链的顶点，预处理向上 $2^i$ 级的节点（倍增表）。
    2. 查询 $u$ 的 $k$ 级祖先时，先跳到 $u$ 的长链顶 $top$。若 $k \le dep[u] - dep[top]$，直接在长链数组里查。
    3. 否则跳到 $top$ 的 $2^i$ 级祖先，递归处理。
  - **复杂度**：预处理 $O(n \log n)$，查询 $O(1)$。
  ```cpp
  #include <bits/stdc++.h>
  using namespace std;
  
  const int N = 5e5 + 5;
  const int LOG = 20;
  
  int n, q;
  vector<int> g[N];
  int dep[N], fa[N][LOG], son[N], len[N], top[N];
  vector<int> chain[N];    // 长链向下节点
  vector<int> up_chain[N]; // 长链向上节点
  
  // 第一次 DFS：求深度、倍增祖先、长儿子
  void dfs1(int u, int p) {
      dep[u] = dep[p] + 1;
      fa[u][0] = p;
      for (int i = 1; i < LOG; i++)
          fa[u][i] = fa[fa[u][i-1]][i-1];
      len[u] = 1;
      for (int v : g[u]) {
          if (v == p) continue;
          dfs1(v, u);
          if (len[v] + 1 > len[u]) {
              len[u] = len[v] + 1;
              son[u] = v;
          }
      }
  }
  
  // 第二次 DFS：构建长链
  void dfs2(int u, int p) {
      if (!top[u]) { // 链顶
          top[u] = u;
          // 向下构建链
          int cur = u;
          while (cur) {
              chain[u].push_back(cur);
              cur = son[cur];
          }
          // 向上构建链（长度 len[u]）
          int x = p;
          for (int i = 0; i < len[u]; i++) {
              up_chain[u].push_back(x);
              if (x) x = fa[x][0];
          }
      }
      for (int v : g[u]) {
          if (v == p) continue;
          if (v != son[u]) {
              top[v] = v;          // 轻儿子是新的链顶
          } else {
              top[v] = top[u];     // 重儿子继承链顶
          }
          dfs2(v, u);
      }
  }
  
  int query(int u, int k) {
      if (k == 0) return u;
      int i = __lg(k);             // k 的最高位
      u = fa[u][i];
      k -= (1 << i);
      int t = top[u];
      int d = dep[u] - dep[t];
      if (k <= d) {
          return chain[t][d - k];
      } else {
          return up_chain[t][k - d];
      }
  }
  
  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);
      cin >> n;
      for (int i = 1, u, v; i < n; i++) {
          cin >> u >> v;
          g[u].push_back(v);
          g[v].push_back(u);
      }
      dfs1(1, 0);
      memset(top, 0, sizeof(top));
      dfs2(1, 0);
      cin >> q;
      while (q--) {
          int u, k;
          cin >> u >> k;
          cout << query(u, k) << "\n";
      }
      return 0;
  }
  ```

### 树哈希（树同构判定）

- **无根树哈希（AHU 算法）**：
  - 找出树的重心（最多两个）。
  - 以重心为根，递归求括号序列（子树按哈希值排序后拼接）。
  - 比较两棵树的括号序列是否相同。
  - 复杂度 $O(n \log n)$。
- **有根树哈希（括号序列法）**：
  - 每个节点 $h_u = \text{hash}(\text{concat}(\text{sort}(h_{v_1}, \dots, h_{v_k})))$。
  - 配合 `std::mt19937_64` 或 `splitmix64` 防止被卡。
  - 复杂度 $O(n \log n)$。
- **树哈希（随机权值法）**：
  - $h_u = \bigoplus_{v \in son(u)} \text{splitmix64}(h_v)$（不排序）。
  - 该方法只能判同构的**必要条件**（易冲突），但极度好写。配合双哈希可防 Hack。

### Kruskal 重构树（瓶颈边问题降维打击）

- 应用
  - 任意两点间的最大瓶颈边查询
  - 多源瓶颈路！！！
    - 就是说，可以有多个中介点
    - 那么用一个超级源点连接所有中介点
    - 然后，新的边权 `w' = dis[u] + dist[v] + w`
    - 所以说，就是上求 `min(dist(a,b), lca(a,b))`

### 支配集 / 点覆盖 / 独立集

- **最小点覆盖**：管的是**边**。每条边至少有一个端点被选。
- **最小支配集**：管的是**点**。每个点要么被选，要么邻居被选。
- **最大独立集**：管的是**点与点的关系**。选中的点两两不相邻。

| 问题 | 状态含义 | 转移关键 |
| :--- | :--- | :--- |
| **最小点覆盖** | `dp[u][0]`: u 不选；`dp[u][1]`: u 选 | u 不选 → 所有儿子必须选；u 选 → 儿子可选可不选 |
| **最小支配集** | `dp[u][0]`: u 被选；`dp[u][1]`: u 不选但被儿子支配；`dp[u][2]`: u 不选被父亲支配 | u 被选 → 儿子可任意状态；u 被儿子支配 → 至少一个儿子选；u 被父亲支配 → 儿子不能被父亲支配 |
| **最大独立集** | `dp[u][0]`: u 不选；`dp[u][1]`: u 选 | u 选 → 所有儿子不能选；u 不选 → 儿子可选可不选 |

- 二分图
  - **最小点覆盖 = 最大匹配**（Kőnig 定理）。
- 任意图
  - **最大独立集 = 总点数 - 最小点覆盖**（互补关系）。
- 支配集没有这种简单的互补关系，通常单独用树形 DP 求。

### 树上最大匹配（贪心）

> 这个海星，给了个快速求解

- **结论**：树上最大匹配可以用贪心 $O(n)$ 求解。
- **做法**：DFS 后序遍历。若当前节点 $u$ 未匹配，且存在一个未匹配的儿子 $v$，则匹配 $(u, v)$。
- **本质**：叶子节点优先匹配，越晚匹配越亏。
- **代码骨架**：
  ```cpp
  int match(int u, int fa) {
      int cnt = 0; // 已匹配的儿子数
      for (int v : g[u]) {
          if (v == fa) continue;
          if (match(v, u)) cnt++;
      }
      if (cnt > 0) return 0; // u 被匹配
      return 1;              // u 未匹配
  }

### 树上最小路径覆盖（两种定义，别搞混！）

> 这个嘛，这个难道不是叫那个 叶子数量 / 2 向上取整吗，卧槽混了

#### 定义一：用最少的点不相交路径覆盖所有顶点

- **结论**：最小路径数 = $n - \text{最大匹配数}$。
- **证明**：每条路径的边数 = 顶点数 - 1。路径边集是匹配的子集。路径数 = $n$ - 路径中使用的边数，最大化使用的边数即最大匹配。
- **例子**：一条链，$n=5$，最大匹配 = 2，路径数 = 3。
  - 路径 $1 \to 2 \to 3$，$4 \to 5$ —— 等等，这是 2 条。
  - 实际上，链的最大匹配是 2（边 $(1,2),(3,4)$），$n - 2 = 3$。但你可以用 3 条路径覆盖：$(1 \to 2), (3 \to 4), (5)$。对，3 条。
- **与二分图一致**：二分图最小路径覆盖 = $n$ - 最大匹配（DAG 拆点建图）。

#### 定义二：用最少的路径覆盖所有边（路径可共享顶点）

- **结论**：最小路径数 = $\lceil L / 2 \rceil$，其中 $L$ 是叶子数。
- **证明**：每条路径最多有两个端点，端点是叶子。至少需要 $\lceil L/2 \rceil$ 条路径。这个下界可以达到（贪心配对叶子）。
- **例子**：星形图，中心 + $k$ 个叶子。$L = k$，路径数 = $\lceil k/2 \rceil$。
- **例子**：一条链，$L = 2$，路径数 = 1（整条链）。

#### 一句话总结

- 覆盖**顶点**：$n - \text{最大匹配}$。
- 覆盖**边**：$\lceil \text{叶子数} / 2 \rceil$。
- 你说的“叶子数量 / 2 向上取整”是**定义二**，不是定义一。

### 树的拓扑序计数

> 可以，本质堆计数

- **结论**：有根树（父先于子）的拓扑序数量 = $\frac{n!}{\prod_{u=1}^n sz[u]}$。
- **直观理解**：$n$ 个节点的全排列有 $n!$ 种，但对每个节点 $u$，它的子树内部必须满足父先于子，子树内部的相对顺序固定了 $sz[u]$ 种排列之一。
- **应用**：树形结构的随机生成、排列计数。

### 树上路径交 / 路径并

> 这个挺不错的 交 与 并

- **两条路径 $(a, b)$ 与 $(c, d)$ 的交**：
  - 交为空 $\iff$ $lca(a,b)$ 不在路径 $(c,d)$ 上 **且** $lca(c,d)$ 不在路径 $(a,b)$ 上。
  - 若相交，交点中深度最大的点为 $\max_{x \in \{lca(a,c), lca(a,d), lca(b,c), lca(b,d)\}} dep[x]$。
- **多条路径的并**：
  - 用虚树解决。将路径端点加入关键点集，建虚树，在虚树上做标记和统计。

### 树上背包的复杂度

> 这个挺神秘的

- **结论**：朴素树上背包是 $O(n^2)$，不是 $O(n^3)$。
- **证明**：合并两个子树时，代价为 $\min(sz[u], K) \times \min(sz[v], K)$，总复杂度为 $O(nK)$。
- **优化**：若容量上限 $K$ 很小，复杂度为 $O(nK)$。若 $K = n$，则为 $O(n^2)$。

### 树的连通块计数（DP）

> 背包方案数

- **问题**：求树上大小为 $k$ 的连通块数量。
- **DP**：`dp[u][j]` 表示以 $u$ 为根的子树中，包含 $u$ 且大小为 $j$ 的连通块数。
- **转移**：合并儿子时，$dp[u][i+j] += dp[u][i] \times dp[v][j]$。
- **复杂度**：$O(n^2)$。
- **应用**：树形结构计数、随机生成。

### 树的直径计数 / 重心计数

- **直径计数**：
  - 若直径长度为偶数：统计所有可能的中心，计算以该中心为根的子树深度分布。
  - 若直径长度为奇数：统计所有可能的中心边，计算两侧深度分布。
- **重心计数**：
  - 重心最多两个。若有两个，它们相邻。
  - 统计最大子树大小 $\le n/2$ 的节点数量。
- **复杂度**：$O(n)$。

### 树的 LIS（最长递增子序列）

- **问题**：树上从根到叶的路径中，最长递增子序列。
- **DP**：`dp[u]` 表示从根到 $u$ 的 LIS 长度。
- **转移**：若 $a[u] > a[fa]$，则 `dp[u] = dp[fa] + 1`，否则 `dp[u] = dp[fa]`。
- **优化**：若要求全局最长，用类似序列 LIS 的二分维护。

```cpp
// 可撤销版（树上 LIS，正确且简洁）
void dfs(int u, int fa) {
    int pos = lower_bound(tails + 1, tails + ans + 1, a[u]) - tails;
    int old = tails[pos];
    tails[pos] = a[u];
    int old_ans = ans;
    if (pos > ans) ans = pos;
    for (int v : g[u]) if (v != fa) dfs(v, u);
    tails[pos] = old;  // 原地恢复
    ans = old_ans;
}
```
