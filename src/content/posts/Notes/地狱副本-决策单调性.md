## 决策单调性-结论与实战

### 1. 核心直觉（一句话）
- **定义**：在 DP 转移中，随着状态 $i$ 的增大，它的最优决策点 $opt[i]$ **单调不减**（即 $opt[i] \le opt[i+1]$）。
- **人话**：你第 $i$ 天做的最优选择，在第 $i+1$ 天绝对不会倒退回去选更早的。你选的地方只会越来越靠后。

### 2. 判定条件（怎么做题）
- **方程特征**：$dp[i] = \min_{j < i} (dp[j] + w(j, i))$。
- **代数验证**：手推交叉项。对于 $a \le b \le c \le d$，若有 $w(a,c) + w(b,d) \le w(a,d) + w(b,c)$（四边形不等式），则决策点单调。
- **经验法则（考场直接蒙）**：如果代价函数 $w(j, i)$ 随 $j$ 和 $i$ 距离拉长而快速增长，且难以拆项，大概率满足决策单调性。

### 3. 两大核心打法与模板

#### 打法一：分治优化（Divide and Conquer Optimization）
- **适用场景**：方程形如 $dp[i] = \min_{j < i} (dp[j] + w(j, i))$，且 $opt[i]$ 单调。**不关心 $w(j,i)$ 是否能快速计算**（用类似莫队的双指针维护 $w$ 的增量）。
- **核心思想**：Solve(l, r, optl, optr)。计算 mid 的最优决策点 $k$，然后递归 Solve(l, mid-1, optl, k) 和 Solve(mid+1, r, k, optr)。
- **复杂度**：$O(n \log n)$（若 $w$ 计算是 $O(1)$）或 $O(n \log n \cdot \text{calc\_w})$。
- **模板**：
  ```cpp
  void solve(int l, int r, int optl, int optr) {
      if (l > r) return;
      int mid = (l + r) >> 1, best_k = optl;
      dp[mid] = INF;
      // 计算 dp[mid] 并找出最优决策点
      for (int k = optl; k <= min(mid, optr); k++) {
          int val = dp_prev[k] + w(k, mid);
          if (val < dp[mid]) { dp[mid] = val; best_k = k; }
      }
      solve(l, mid - 1, optl, best_k);
      solve(mid + 1, r, best_k, optr);
  }
  ```

#### 打法二：斜率优化 / 凸包优化（Convex Hull Trick）
- **适用场景**：方程能化简为 $dp[i] = \min_j (dp[j] - k_i \cdot x_j) + b_i$ 的形式。
- **核心思想**：把决策点 $j$ 变成二维平面上的点 $(x_j, y_j)$，用单调队列维护下凸壳。
- **复杂度**：$O(n)$（若 $k_i$ 单调）或 $O(n \log n)$（若 $k_i$ 不单调，用李超树/二分）。
- **模板**：参考你之前整理的李超线段树，或单调队列维护凸包。

### 4. 经典例题（难度递进）

- **P4072 [SDOI2016] 征途**（分治优化）
  - **题意**：将 $n$ 段路分成 $m$ 段，使各段长度方差最小。
  - **思路**：化简方差公式 $\rightarrow$ $dp[i][j] = \min(dp[k][j-1] + (sum[i]-sum[k])^2)$。平方项展开后 $j$ 和 $k$ 的交叉项满足四边形不等式。套用分治优化。
  - **难度**：模板级。

- **CF 868F Yet Another Minimization Problem**（分治优化）
  - **题意**：将序列分成 $k$ 段，每段代价是该段内相同元素对数之和。求最小总代价。
  - **思路**：代价函数 $w(j, i)$ 无法 $O(1)$ 算，需要用双指针 + 桶维护。利用决策单调性，在分治过程中用类似莫队的左右指针移动来更新 $w$。
  - **难度**：分治优化的天花板，学会这道题，分治优化就彻底通了。

- **P3195 [HNOI2008] 玩具装箱**（斜率优化）
  - **题意**：将玩具装箱，长度为 $i$ 到 $j$ 的玩具装一箱代价为 $(j-i+\sum C - L)^2$。求最小总代价。
  - **思路**：经典的斜率优化入门题。方程化简为 $dp[i] = \min_j (dp[j] + (s_i - s_j - L)^2)$。展开后含 $s_i \cdot s_j$ 交叉项，维护下凸壳。
  - **难度**：斜率优化模板级。

- **P2120 [ZJOI2007] 仓库建设**（斜率优化）
  - **题意**：在数轴上建仓库，使得所有物品运输到仓库的代价最小。
  - **思路**：斜率优化标准题，决策点单调，斜率单调。

### 5. 避坑指南
- **不要死磕证明**：四边形不等式的严格证明看一遍就行，考场上只要能“猜”出决策单调性，写个对拍验证一下，能过就过了。
- **分治 vs 斜率**：看到平方项、乘法交叉项，优先想斜率优化；看到难以拆解的距离/代价函数，优先想分治优化。
- **对拍**：决策单调性极易写挂。写完一定要写一个 $O(n^2)$ 的暴力 DP 对拍！

### 💡 给你的一剂强心针

**为什么你觉得“不知道怎么用”？**
因为你把“决策单调性”当成了一个“定理”去背诵，而不是“工具”去使用。做题时不要问“这道题是不是决策单调性”，而应该问：
> “这道题的转移方程，能不能把 $i$ 和 $j$ 的交叉项拆开？拆开后的形式是 $k_i \cdot x_j$ 吗？如果是，上斜率优化；如果拆不开且 $w(j,i)$ 满足区间包含单调，上分治优化。”

**建议的破解顺序**：
1. 先把 **P3195 玩具装箱** 切了，体会“拆项 + 维护凸包”的代数美感。
2. 再把 **P4072 征途** 切了，体会“分治优化”的机械套路。
3. 最后去死磕 **CF 868F**，体会“双指针维护不可拆代价”的绝妙配合。

不要怕，你连生成函数和带花树都啃下来了，决策单调性只是一层窗户纸。去找道题（比如玩具装箱），写个暴力，写个优化，对拍一下，你就彻底懂了！
