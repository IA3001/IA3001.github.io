## 树论-结论

### 重心

- **重心**：删去该点后最大连通块大小最小。最大子树大小 $\le \frac{n}{2}$；所有点到重心距离和最小；两树合并重心在连接两树重心的路径上。

### 直径

- **直径性质**：
  - 任意点的最远点必为直径的一个端点。
  - 两棵树合并，新直径端点必在原来两棵树直径的 4 个端点中产生。
- **直径求法**：
  - 非负权树：两次 DFS/BFS。
  - 带负权边：树形 DP，`dp[u][0]` 记录向下最长路，`dp[u][1]` 记录向下次长路，`ans = max(dp[u][0] + dp[u][1])`。

### 中心

- **树的中心**：到其他点最大距离最小的点。中心一定在直径上。
- **中心性质**：直径长度为偶数时，中心唯一；直径为奇数时，中心为中间边的两个端点。
- **中心求法**：
  - 求出直径路径，取中点。
  - 树形 DP 求出每个点的最远距离 `max(dp[u][0], up[u])`，取最小值。

### LCA

#### 两点 LCA

- **倍增法**：$O(n \log n)$ 预处理，$O(\log n)$ 查询。空间 $O(n \log n)$。最通用，常数适中。
- **DFS序 / 欧拉序 + ST 表**：$O(n \log n)$ 预处理，$O(1)$ 查询。适合查询次数极多的情况。
- **Tarjan 离线**：$O(n + q)$。并查集实现，仅限离线且查询已知的情况。
- **树链剖分**：$O(n)$ 预处理，$O(\log n)$ 查询。常数极小，常与树剖的其他操作一并使用。

#### 多点 LCA

- **定义**：树上 $k$ 个点 $v_1, v_2, \dots, v_k$ 的 LCA（即所有点的公共祖先中深度最大的点）。
- **核心结论**：多点 LCA 等于这 $k$ 个点中 **DFS序最小** 和 **DFS序最大** 的两个点的 LCA。
  - 即 $lca(v_1, \dots, v_k) = lca(v_{min\_tin}, v_{max\_tin})$。
- **点集到 LCA 的距离和**：$\sum_{i=1}^k dist(v_i, lca) = \sum depth[v_i] - k \cdot depth[lca]$。
- **虚树构建**：利用多点 LCA 性质，关键点按 `tin` 排序后，相邻两点求 LCA 加入集合，即可在 $O(k \log k)$ 内建成虚树。

### DFS 序

- **定义**：节点第一次被访问的时间戳 $tin[u]$。
- **子树区间**：子树在 DFS 序中对应连续区间 $[tin[u], tout[u]]$。
- **大小关系**：$tin[u] + sz[u] - 1 = tout[u]$。
- **祖先判定**：$u$ 是 $v$ 的祖先 $\iff tin[u] \le tin[v] \le tout[u]$。
- **LCA 性质**：$u$ 和 $v$ 的 LCA 是它们的公共祖先中**深度最小的父亲**。
- **应用**：
  - 子树修改/查询：转化为区间操作（配合线段树/树状数组）。
  - 虚树构建：关键点按 $tin$ 排序，单调栈维护右链。
  - 树上差分：路径修改转化为单点修改，按 $tin$ 逆序累加。

### Euler 序 / 括号序

- **定义**：进入节点和回溯节点均记录一次，序列长度为 $2n-1$。
- **LCA 性质**：$u$ 和 $v$ 的 LCA 是 Euler 序中 $u$ 和 $v$ 第一次出现位置之间深度最小的节点。
- **求 LCA 复杂度**：配合 ST 表，预处理 $O(n \log n)$，查询 $O(1)$。
- **括号序性质**：若在进入时标记 $+1$，回溯时标记 $-1$，则前缀和为深度。
- **应用**：
  - $O(1)$ LCA。
  - 树上莫队：将树上路径查询转化为序列区间查询（注意特判 LCA 是否包含在内）。
  - 欧拉回路与 Euler 序区分：图论的 Euler 序是经过所有边恰好一次的序列，树的 Euler 序是访问节点的序列。

### Prufer 序列与 Cayley 公式

- **Cayley公式**：$n$ 个节点的完全图生成树数量为 $n^{n-2}$。
- **Prufer序列**：树与长度为 $n-2$ 的序列双射。节点 $i$ 出现次数等于 $deg(i) - 1$。
- **度限制生成树计数**：已知每个点度数 $d_i$，方案数为 $\frac{(n-2)!}{\prod_{i=1}^n (d_i - 1)!}$。

### 虚树 (Virtual Tree)
- **性质**：关键点集大小为 $k$ 时，虚树总点数不超过 $2k$。
- **构建**：按 DFS 序排序，相邻点求 LCA 加入集合，单调栈维护右链连边。
- **复杂度**：$O(k \log k)$。

### 换根 DP
- **套路**：第一次 DFS 自底向上求子树信息 `down[u]`；第二次 DFS 自顶向下求全局信息 `up[v] = up[u] + down[u] - (down[v] + sz[v]) + (n - sz[v])`。
- **复杂度**：$O(n)$。

### 基环树
- **定义**：$n$ 点 $n$ 条边的连通图。
- **套路**：拓扑排序或 Tarjan 找环。断环成树，对环上每个点的子树跑树形 DP，最后在环上做环形 DP（或单调队列优化）。

### 树上启发式合并 (DSU on Tree)
- **套路**：剖分重儿子。递归轻儿子计算答案并清除影响；递归重儿子计算答案并保留影响；暴力合并轻儿子子树至重儿子。
- **复杂度**：$O(n \log n)$。
