## 数列求和

- 纯等比
  - 高中知识
- 幂 乘 等比（比较纯粹 但是难求）
  - 衍生： $\sum i^k$
- 组合数 乘 等比（不太纯粹 但是好求 ）
  - 上指标同步
    - $\sum \binom{i}{k}x^i$
  - 下指标同步
    - $\sum \binom{k}{i}x^i$

---

### 1. 纯等比

| 形式幂级数 (和式) | 封闭形式 (原函数) | 推导核心操作 | 竞赛实用备注 |
| :--- | :--- | :--- | :--- |
| $\sum_{i=0}^{n}x^i$ | $\frac{1-x^{n+1}}{1-x}$ | **错位相减法** | 表示“取 $0 \sim n$ 个”的有限约束。 |
| $\sum_{i=m}^{n}x^i$ | $\frac{x^m - x^{n+1}}{1-x}$ | **提取公因式** $x^m$ | 表示取下标区间 $[m, n]$ 的约束。 |

---

### 2. "幂" 乘 等比

| 形式幂级数 (和式) | 封闭形式 (原函数) | 推导核心操作 | 竞赛实用备注 |
| :--- | :--- | :--- | :--- |
| $\sum_{i=1}^{n}ix^i$ | $\frac{x-(n+1)x^{n+1}+nx^{n+2}}{(1-x)^2}$ | **求导**：对基础式两边求导后乘 $x$ | 求加权和的期望或组合计数。 |
| $\sum_{i=1}^{n} i^2 x^i$ | $\frac{x(1+x) - x^{n+1}[(n+1)^2 - (2n^2+2n-1)x + n^2 x^2]}{(1-x)^3}$ | **求导**：对 $\sum i x^i$ 的结果再求导后乘 $x$ | 二阶矩/方差计算，极度繁琐，**强烈建议拆成无穷和减尾项**。 |

> $\sum i^2 x^i$ 推导方法：**无穷和与降维打击**
> 
> **1. 先求无穷和（无穷级数）**
> 
> 已知无穷和基础 $\sum_{i=0}^{\infty} x^i = \frac{1}{1-x}$
>
> 求导乘 $x$：$\sum_{i=1}^{\infty} i x^i = \frac{x}{(1-x)^2}$
>
> 再求导乘 $x$：$\sum_{i=1}^{\infty} i^2 x^i = x \cdot \frac{d}{dx} \left( \frac{x}{(1-x)^2} \right) = x \cdot \frac{(1-x)^2 + 2x(1-x)}{(1-x)^4} = \frac{x(1+x)}{(1-x)^3}$
>
> **这就是最清爽的封闭形式（分子只有两项！）**
> 
> **2. 减去尾巴（有限和）**
>
> 有限和 $\sum_{i=1}^{n} i^2 x^i = \sum_{i=1}^{\infty} i^2 x^i - \sum_{i=n+1}^{\infty} i^2 x^i$
>
> 对于尾项，做换元令 $j = i - (n+1)$，则 $i = n+1+j$：
>
> 尾项 $= \sum_{j=0}^{\infty} (n+1+j)^2 x^{n+1+j} = x^{n+1} \sum_{j=0}^{\infty} (n+1+j)^2 x^j$
>
> 然后利用 $(n+1+j)^2 = (n+1)^2 + 2(n+1)j + j^2$ 展开，代回前面求出的无穷和公式 $\sum x^j, \sum j x^j, \sum j^2 x^j$，合并同类项即可得到与“暴力求导法”完全一致的结果。
>
> **懂了**，就是用无穷和的自相残杀，得到有限和
>
> 但是啊但是，即使如此，我依然没有看到我想看到的那个求法：
>
> 用组合数 表示 一个幂！！！
>
> 那么， Ta 来啦！！！

#### 幂 $\leftrightarrow$ 组合数

将高次幂 $i^k$ 拆解为**下降幂**和**组合数**的线性组合，彻底规避求导的繁琐。

- **核心代换**：
  - $i = \binom{i}{1}$
  - $i^2 = 2\binom{i}{2} + \binom{i}{1}$
  - $i^3 = 6\binom{i}{3} + 6\binom{i}{2} + \binom{i}{1}$
  - $i^4 = 24\binom{i}{4} + 36\binom{i}{3} + 14\binom{i}{2} + \binom{i}{1}$

- **通用公式（第二类斯特林数 $S(k, j)$）**：
  - $i^k = \sum_{j=0}^k S(k, j) j! \binom{i}{j}$

### 3. "二项式" 乘 等比

#### 下指标同步（有限和）

| 形式幂级数 (和式) | 封闭形式 (原函数) | 推导核心操作 | 竞赛实用备注 |
| :--- | :--- | :--- | :--- |
| $\sum_{i=0}^{n}\binom{n}{i}x^i$ | $(1+x)^n$ | **二项式定理** | 生成函数中处理组合数卷积。 |
| $\sum_{i=0}^{n}\binom{n}{i}$ | $2^n$ | 取 $x=1$ | 组合数求和经典结论。 |
| $\sum_{i=0}^{n}(-1)^i\binom{n}{i}$ | $0$ | 取 $x=-1$ | 奇偶项抵消结论。 |
| $\sum_{i=0}^{n}i\binom{n}{i}x^i$ | $nx(1+x)^{n-1}$ | **对二项式定理求导后乘 $x$**（最直观） | 带权组合数和（求期望常客）。 |
| $\sum_{i=0}^{n}i^2\binom{n}{i}x^i$ | $nx(1+nx)(1+x)^{n-2}$ | **组合数代换** + 吸收恒等式（也可以同上） | 二阶矩/方差计算。 |

> **推导过程（以 $i^2$ 为例，吸收恒等式代数平移）**：
> 
> 1. 组合数代换：$i^2 = 2\binom{i}{2} + \binom{i}{1}$
>
> 2. 代入求和：$\sum_{i=0}^{n} i^2 \binom{n}{i} x^i = 2\sum_{i=0}^{n} \binom{i}{2}\binom{n}{i} x^i + \sum_{i=0}^{n} \binom{i}{1}\binom{n}{i} x^i$
>
> 3. 应用**吸收恒等式** $\binom{i}{j}\binom{n}{i} = \binom{n}{j}\binom{n-j}{i-j}$：
> $= 2\sum_{i=0}^{n} \binom{n}{2}\binom{n-2}{i-2} x^i + \sum_{i=0}^{n} \binom{n}{1}\binom{n-1}{i-1} x^i$
>
> 4. 提取常数，凑二项式定理：
> $= 2\binom{n}{2} x^2 (1+x)^{n-2} + \binom{n}{1} x (1+x)^{n-1} = nx(1+nx)(1+x)^{n-2}$

#### 上指标同步（无穷和？！！）

> **悲报：** 上指标同步 的 有限和 无简单封闭形式
>
> 唯一的特例只有 $x = 1$ （曲棍球棒恒等式）
>
> $\sum_{i=0}^{n} \binom{i}{k} = \binom{n+1}{k+1}$

| 形式幂级数 (和式) | 封闭形式 (原函数) | 推导核心操作 | 竞赛实用备注 |
| :--- | :--- | :--- | :--- |
| $\sum_{i=0}^{\infty}\binom{i}{k}x^i$ | $\frac{x^k}{(1-x)^{k+1}}$ | **负二项定理/连续求导** | 处理纯幂乘等比的神器。 |

> **推导过程**：由 $\sum_{i=0}^{\infty} x^i = \frac{1}{1-x}$，两边连续求导 $k$ 次，再除以 $k!$ 即可得到。
> 
> **实战（求 $\sum i^2 x^i$）**：
>
> $i^2 = 2\binom{i}{2} + \binom{i}{1}$
>
> $= 2\sum \binom{i}{2}x^i + \sum \binom{i}{1}x^i = 2 \cdot \frac{x^2}{(1-x)^3} + \frac{x}{(1-x)^2} = \frac{x(1+x)}{(1-x)^3}$

#### Bug 补充一个“绝处逢生”小技巧（关于上指标有限和的实战）

*   当 $n$ 极大（如 $10^{18}$），但 $k$ 很小（如 $k \le 10^5$）时，怎么求 $\sum_{i=0}^n \binom{i}{k}$？
*   **答案**：不要想着求和的闭式，直接把 $\sum_{i=0}^n \binom{i}{k}$ 看成 $O(n)$ 的遍历！
*   **加速技巧**：利用 $\binom{i}{k} = \binom{i-1}{k} + \binom{i-1}{k-1}$ 的递推，维护一个大小为 $k$ 的数组，整体复杂度是 $O(k)$ 或 $O(k \log \text{MOD})$。
*   **终极绝招**：如果 $n$ 巨大但 $k$ 极小，可以尝试用拉格朗日插值（因为 $S(n, k) = \sum_{i=0}^n \binom{i}{k}$ 是关于 $n$ 的 $k+1$ 次多项式）。**这就是表格里“上指标有限和（地狱）”的破局之法**。

## 后记：有限和 与 无穷和 转换

在算法竞赛中，很多时候题目给的是有限和（比如求前 $n$ 项的期望），直接算容易超时。核心思路是：
1. **先算无穷和**：利用无穷级数的封闭形式（如 $\frac{1}{1-x}$）。
2. **再减去多余项**：无穷和减去从 $n+1$ 开始的尾项，或者利用公式 $\sum_{i=0}^{n} x^i = \frac{1-x^{n+1}}{1-x}$ 直接一步到位。

**记忆口诀**：
- **有限等比找错位**：基础 $\sum x^i$ 用错位相减。
- **组合系数找二项**：看到 $\binom{n}{i}$ 直接上 $(1+x)^n$。
- **求导乘 $x$ 加权重**：遇到 $i$ 乘系数（$i \binom{n}{i}$ 或 $i x^i$），闭眼求导再乘 $x$。
- **上指标有限和，无简洁公式，要么前缀和要么无条件避难。**
