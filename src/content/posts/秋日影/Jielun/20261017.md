> 维护 有序 滑动窗口 的 中位数 到各个点的距离之和
> 
> 即：最小 同一化 代价！
> 
> 其实是可以动态维护的！！！
> 

原理

- （右扩）
	- 奇数长度 -> 偶数长度：
		- 认为是从以 mid 为中心，到以 左 mid 为中心
	- 偶数长度 -> 奇数长度：
		- 认为是从以 右 mid 为中心（因为 sum 左 mid = sum 右 mid），到以 mid 为中心
	- 故均为 `+= a[r] - a[(l + r) / 2]`
- （左扩）
	- 同理啊
	- 故为 `+= a[l] - a[(l + r + 1) / 2]`
### Code

```cpp
// 小茵 NB !
void Solve() {
    cin >> n >> k;
    a.resize(n);
    for (auto& x : a) {
        cin >> x;
    }
    sort(a.begin(), a.end());
    ll cur = 0;
    int l = 0;
    int res = 0;
    for (int r = 0; r < n; r++) {
        cur += a[r] - a[(r + l) / 2];
        while (cur > k) {
            // cout << l << ',' << r << ',' << cur << endl;
            cur -= a[(r + l + 1) / 2] - a[l];
            l++;
        }
        // cout << l << ',' << r << ',' << cur << endl;
        res = max(res, r - l + 1);
    }
    cout << res;
}
```
