## 【高数】球缺体积计算公式

直接三重积分 

$$
\begin{align}

V(R, h) &= \iiint_{x^2+y^2+z^2 \le R^2 , \\ R - h \le x \le R} 1 \ dx \\

&= \int_{R-h}^{R} \iint_{y^2+z^2 \le R^2 - x^2} 1 \ d\sigma \ dx \\

&= \int_{R-h}^{R} \pi (R^2 - x^2) \ dx \\

&= \pi (R^2 - x^2) \bigg|_{R-h}^{R} \\

&= \pi h ^2 (R - \frac{h}{3}) 
\end{align}
$$

```cpp
double cal(double R, double h) {
	if (sign(h - R) == 1) return pi * R * R * R * 4 / 3 - cal(R, R*2 - h);
	return pi * h * h * (R - h / 3);
}
```

## 【强化认知】卡特兰数

- 定义可以是：
	- 1 - n 的数字，按顺序逐个入栈 / 出栈的合法方案数
- 拓展 $Catalan'(n) = Catalan(n) - Catalan(n-1)$ 
	- 表示固定第一个数字 1 入栈立即出栈，所有的方案数

$$
Catalan(n) = \frac{1}{n+1} \binom{2n}{n}
$$
