## G2 区间博弈 DP

### Problem Description

有一个在序列 $c$ 上的博弈，$A$ 先手：
- $A$ 选择 $i$：`c[i] = min(c[i], c[i + 1])` 并删除 $c[i + 1]$
- $B$ 选择 $i$：`c[i] = max(c[i], c[i + 1])` 并删除 $c[i + 1]$

$A$ 希望最大化最后剩下的 $c[1]$，定义最终剩下的值为 $f(c)$。

给定长度为 $n$ 的排列 $p$（有空缺项），求所有可能中**最大的** $p$ 的所有子数组的 $f()$ 之和。

数据范围：$1 \le n \le 5 \times 10^5$

### Solution

**博弈公式、乘法原理、奇偶二分类、黑白二分类、路径贡献法、Slope Trick、斜率优化 DP**

首先一定要推导博弈公式：
- 使用**01二分答案**求解博弈答案
- 假设答案为 $m$，那么 $\ge m$ 的都设置为 $1$，其他都是 $0$
- 首先考虑奇偶性：
  - 奇数长度最后取 $\max$：
    - $k = 1$：需要 $\max(c[1], c[m]) \ge m$
    - $k = 3$：一旦两侧有 $1$，一定可以避免操作有 $1$ 的位置，然后到达 $k-2$ 状态（true）
    - 否则全 $0$，那么 $B$ 一定可以避免操作两端，达到 $00$ 状态（false）
  - 偶数长度最后取 $\min$，必然要求 $m \le c[1]$：
    - $k = 2$：需要 $\min(c[1], c[2]) \ge m$
    - $k = 4$：全 $1$ 那么一定可以达到 $11$ 状态（true）
    - 否则一旦两侧有 $0$，那么 $B$ 一定会避免操作有 $0$ 的位置，剩下至少一个 $0$ 给 $A$ 操作（false）
- 所以博弈公式为 $f(c) = k \& 1 ? \max(c[1], c[k]) : \min(c[1], c[k])$

但是为了求解这个 DP 答案，需要公式转化：

$$
\begin{aligned}
\text{ans} &= \sum_{i \le j} [i \equiv j \bmod 2] \max(p_i, p_j) + \sum_{i \le j} [i \not\equiv j \bmod 2] \min(p_i, p_j) \\
\text{补偿法} &= \sum_{i \le j} \max(p_i, p_j) + \sum_{i \le j} [i \not\equiv j \bmod 2] (\min(p_i, p_j) - \max(p_i, p_j)) \\
\text{枚举答案法} &= \sum_{i=1}^n i^2 - \sum_{i<j} [i \not\equiv j \bmod 2] |p_i - p_j| \\
&= \frac{n(n+1)(2n+1)}{6} - \text{数轴上两种阵营异色距离之和}
\end{aligned}
$$

而一个**数轴**可以看作一个**链状树**，答案要求的是**数轴上** **最小** **两阵营** **距离之和**；可以看作是一个树，因此可以考虑边的贡献：一个边被使用了多少次？当然是左右两侧对应的异色点之积。

由于**二分类 DP** 的**补集可预测性**，这大大化简了求解 DP 的难度：
- 设 $\text{dp}[i][j]$ 表示数轴上前 $i$ 个数字染 $j$ 个黑点（即染 $i-j$ 个白点）**"至少需要的"**（因为仅计算前 $i$ 个边）的最小异色距离之和
- **溯源法**：
  - $i$ 可染黑色：$\text{dp}[i][j] \xleftarrow{\text{chmin}} \text{dp}[i-1][j-1] + j \times (\lfloor n / 2 \rfloor - (i-j)) + (i-j) \times (\lceil n / 2 \rceil - j)$
  - $i$ 可染白色：$\text{dp}[i][j] \xleftarrow{\text{chmin}} \text{dp}[i-1][j] + j \times (\lfloor n / 2 \rfloor - (i-j)) + (i-j) \times (\lceil n / 2 \rceil - j)$
- **贡献法**：
  - $i+1$ 可染黑色：$\text{dp}[i+1][j+1] \xleftarrow{\text{chmin}} \text{dp}[i][j] + (j+1) \times (\lfloor n / 2 \rfloor - ((i+1)-(j+1))) + ((i+1)-(j+1)) \times (\lceil n / 2 \rceil - (j+1))$
  - $i+1$ 可染白色：$\text{dp}[i+1][j] \xleftarrow{\text{chmin}} \text{dp}[i][j] + j \times (\lfloor n / 2 \rfloor - ((i+1)-j)) + ((i+1)-j) \times (\lceil n / 2 \rceil - j)$
- 显然**溯源法**更简洁

答案为 $\frac{n(n+1)(2n+1)}{6} - \text{dp}[n][\lceil n/2 \rceil]$。
