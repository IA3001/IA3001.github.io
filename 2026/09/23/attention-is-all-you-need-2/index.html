  • d = 2

完全图最大分隔数 （使用 欧拉公式）

只是题面答案多了个 n

  • VVV 点，EEE 边，FFF 面
    • V−E+F=2V-E+F=2V−E+F=2
  • 强大的欧拉公式方便我们数 面 的个数，因为
    • EEE 边最好求
    • VVV 点稍微好求
      • 需要求交点
    • FFF 自然算出来
  • 所以，不要认为，欧拉公式只是用于高维的图形，二维平面依然可以

Finside=E−V+1F_{\text{inside}} = E - V + 1 Finside​=E−V+1

  • 先算 边
    • E=(n2)E = \binom{n}{2}E=(2n​) ?
    • 边真的算对了吗？
    • 错！还有点，交点引发的小边，绝对不可以是算大边！
    • 每有一个交点，显然他就切割了2次边，所以贡献是 2
    • E=(n2)+2(n4)E=\binom{n}{2} + 2 \binom{n}{4}E=(2n​)+2(4n​)
  • 再算点
    • 基本点 nnn
    • 交点（由两条线的交点确定？）
      • 我们不那么枚举
      • 而是枚举，一个四边形，因为一个交点确定对应一个四边形的对角线交点
      • (n4)\binom{n}{4}(4n​)
    • V=n+(n4)V=n + \binom{n}{4}V=n+(4n​)
  • 所以
    • F=(n2)+(n4)−n+1F = \binom{n}{2} + \binom{n}{4} - n + 1F=(2n​)+(4n​)−n+1

这个题目的答案就是
F=(n2)+(n4)+1F=\binom{n}{2}+\binom{n}{4}+1F=(2n​)+(4n​)+1
