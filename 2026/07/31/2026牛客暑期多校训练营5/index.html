C 数字游戏

Problem Description

  • Input file: standard input
  • Output file: standard output
  • Time limit: 1 second
  • Memory limit: 256 megabytes

给定一个正整数进制 BBB。

你需要构造三个长度为 BBB 的排列 P,Q,RP, Q, RP,Q,R（即每个序列恰好包含 000 到 B−1B-1B−1 每个数字一次）。

P=(p1,p2,…,pB),Q=(q1,q2,…,qB),R=(r1,r2,…,rB).P = (p_1, p_2, \dots, p_B),\quad Q = (q_1, q_2, \dots, q_B),\quad R = (r_1, r_2, \dots, r_B). P=(p1​,p2​,…,pB​),Q=(q1​,q2​,…,qB​),R=(r1​,r2​,…,rB​).

定义一个序列 X=(x1,x2,…,xB)X = (x_1, x_2, \dots, x_B)X=(x1​,x2​,…,xB​) 在 BBB 进制下表示的整数为

[X]B=∑i=1Bxi⋅BB−i.[X]_B = \sum_{i=1}^{B} x_i \cdot B^{B-i}. [X]B​=i=1∑B​xi​⋅BB−i.

注意序列允许以数字 000 开头，因此表示的整数可以小于 BB−1B^{B-1}BB−1。

请你构造三个排列 P,Q,RP, Q, RP,Q,R，使得它们满足等式（注意加法是在 BBB 进制下的加法）

[P]B+[Q]B=[R]B,[P]_B + [Q]_B = [R]_B, [P]B​+[Q]B​=[R]B​,

并且对于每个位置 iii（1≤i≤B1 \le i \le B1≤i≤B），pi,qi,rip_i, q_i, r_ipi​,qi​,ri​ 两两不同。

如果不存在这样的构造，请输出 −1-1−1。

Input

输入仅一行，包含一个整数 BBB（2≤B≤1062 \le B \le 10^62≤B≤106）。

Output

如果存在合法构造，则输出三行，每行 BBB 个整数，分别表示序列 P,Q,RP, Q, RP,Q,R 中的数字，数字之间用空格分隔。

如果不存在合法构造，则输出一行 −1-1−1。

若存在多种构造，输出任意一种即可。

Sample Input

样例 1：

5

样例 2：

6

Sample Output

样例 1：

-1

样例 2：

4 2 5 0 3 1
0 4 1 2 5 3
5 1 0 3 2 4

Hint

2≤B≤1062 \le B \le 10^62≤B≤106。

Solution

数学场典型计算方式：

  • 整体求和得到不变量性质
    • 即 将每一位的 ai+bi+carrayi=ci+carryi+1×Ba_i + b_i + \text{carray}_i = c_i + \text{carry}_{i+1} \times Bai​+bi​+carrayi​=ci​+carryi+1​×B 求和
    • 再利用天然整除约束得出约束条件
  • 奇偶数重排的加法性质
    • 奇数+奇数=偶数集+进位
    • 偶数+偶数=偶数集+进位
    • 由此通过偶数+进位可得奇数集
  • 循环移位后加法的进位性质
    • 很有规律，天然规律

#include<bits/stdc++.h>
using namespace std;

const int N = 1e6 + 5;

int n;

void solve() {
    cin >> n;
    // cout << n << "\n";
    if ((n&1) || n == 2) cout << -1 << "\n";
    else if(n == 4){
        cout << "1 3 0 2\n0 1 2 3\n2 0 3 1\n";
    } else {
        vector<vector<array<int,3>>> nom(n),pls(n);
        for(int i = 0;i<n;i+=2) {
            int a = i, b = (i - 2 + n) % n;
            int c = (a + b) % n, car = (a + b) / n;
            if (car) {
                pls[c].push_back({a, b, c});
            } else {
                nom[c].push_back({a, b, c});
            }
        }
        for(int i = 1;i<n;i+=2) {
            int a = i, b = (i - 2 + n) % n;
            int c = (a + b) % n, car = (a + b) / n;
            if (car) {
                pls[c].push_back({a, b, c});
            } else {
                nom[c].push_back({a, b, c});
            }
        }
        vector<array<int,3>> ans(n);
        int i = 0;
        assert(nom[n-2].size()==2);
        assert(pls[0].size()==2);
        ans[i++] = nom[n-2][1];
        nom[n-2][0][2]++;
        ans[i++] = nom[n-2][0];
        pls[0][0][2]++;
        ans[i++] = pls[0][0];
        ans[i++] = pls[0][1];
        for(int j = 2;j<n-2;j+=2) {
            assert(nom[j].size() == 1);
            assert(pls[j].size() == 1);
            nom[j][0][2]++;
            ans[i++] = nom[j][0];
            ans[i++] = pls[j][0];
        }
        for(int i = 2;i<n;i+=2) {
            if(ans[i][0] == ans[i][2] || ans[i][1] == ans[i][2]) {
                swap(ans[i], ans[i+1]);
                swap(ans[i][2], ans[i+1][2]);
            }
        }
        for(int j =0;j<3;j++) {
            for(int i = 0;i<n;i++) {
                cout << ans[i][j] << " ";
            }cout << "\n";
        }
    }
}

int main() {
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);
    int T = 1;
    // cin >> T;
    while (T--) solve();
}
