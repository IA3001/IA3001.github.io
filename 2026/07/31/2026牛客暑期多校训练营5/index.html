B 放大的徽章

Problem Description

  • Input file: standard input
  • Output file: standard output
  • Time limit: 3 seconds
  • Memory limit: 512 megabytes

平面上给定两个有限格点集合 AAA 和 BBB。设 P=conv⁡(A)P = \operatorname{conv}(A)P=conv(A)，Q=conv⁡(B)Q = \operatorname{conv}(B)Q=conv(B) 分别为它们的凸包。输入中可能包含重复点。

对于一个正整数 kkk，将 PPP 关于原点放大 kkk 倍，得到多边形 kPkPkP。

如果整数向量 (u,v)(u, v)(u,v) 使得平移后的多边形 kP+(u,v)kP + (u, v)kP+(u,v) 与 QQQ 至少有一个公共点，则称 (u,v)(u, v)(u,v) 是合法的。边界相交也算相交。

对于每个询问 kkk，求合法整数向量 (u,v)(u, v)(u,v) 的数量，并对 998244353998244353998244353 取模。

Input

第一行包含三个整数 n,m,qn, m, qn,m,q（3≤n,m≤2×1053 \le n, m \le 2 \times 10^53≤n,m≤2×105，1≤q≤2×1051 \le q \le 2 \times 10^51≤q≤2×105），分别表示 AAA 中点的个数、BBB 中点的个数和询问次数。

接下来 nnn 行，每行包含两个整数 xi,yix_i, y_ixi​,yi​（−109≤xi,yi≤109-10^9 \le x_i, y_i \le 10^9−109≤xi​,yi​≤109），表示 AAA 中的一个点。

接下来 mmm 行，每行包含两个整数 xi,yix_i, y_ixi​,yi​（−109≤xi,yi≤109-10^9 \le x_i, y_i \le 10^9−109≤xi​,yi​≤109），表示 BBB 中的一个点。

接下来 qqq 行，每行包含一个整数 kkk（1≤k≤10181 \le k \le 10^{18}1≤k≤1018），表示一次询问。

保证 PPP 和 QQQ 的面积均为正。

在样例中，PPP 是顶点为 (0,0),(2,0),(2,1),(0,1)(0,0),(2,0),(2,1),(0,1)(0,0),(2,0),(2,1),(0,1) 的矩形，QQQ 是顶点为 (0,0),(3,0),(1,2),(0,1)(0,0),(3,0),(1,2),(0,1)(0,0),(3,0),(1,2),(0,1) 的四边形。

可以算出 2SP=42S_P = 42SP​=4，2SQ=72S_Q = 72SQ​=7，BP=6B_P = 6BP​=6，BQ=7B_Q = 7BQ​=7，且 2SQ+(−P)=252S_{Q+(-P)} = 252SQ+(−P)​=25。因此询问 kkk 的答案为

2k2+10k+8.2k^2 + 10k + 8. 2k2+10k+8.

代入 k=1,2,5,10k = 1, 2, 5, 10k=1,2,5,10，答案分别为 20,36,108,30820, 36, 108, 30820,36,108,308。

Solution

  • 知道闵可夫斯基和
  • 但是忘了 Pick 定理可以用（还以为这一题不是整数格点）
  • 但是完全不知道，一个动态闵可夫斯基凸包的边，用多项式就能表达格点数量？！
    • 完全没想到：动态 Minkowski 凸包的格点数，能压成一个关于 kkk 的多项式。

① 建模：Minkowski 和

∃ p∈P,  q∈Q,  kp+t=q    ⟺    t∈Rk=Q+(−kP)\exists\, p \in P,\; q \in Q,\; kp + t = q \;\;\Longleftrightarrow\;\; t \in R_k = Q + (-kP) ∃p∈P,q∈Q,kp+t=q⟺t∈Rk​=Q+(−kP)

答案 = 凸多边形 RkR_kRk​ 内的格点数。

② 求格点数：Pick 定理

#(X∩Z2)=S(X)+B(X)+22\#(X \cap \mathbb{Z}^2) = \frac{S(X) + B(X) + 2}{2} #(X∩Z2)=2S(X)+B(X)+2​

其中 SSS 为二倍面积，BBB 为边界格点数（不是几何边长）。

③ 关键：RkR_kRk​ 的面积和边界格点都能拆

S(Rk)=S(Q)+k2S(P)+kC,C=S(R1)−S(Q)−S(P)S(R_k) = S(Q) + k^2 S(P) + kC, \qquad C = S(R_1) - S(Q) - S(P) S(Rk​)=S(Q)+k2S(P)+kC,C=S(R1​)−S(Q)−S(P)

B(Rk)=B(Q)+k B(P)B(R_k) = B(Q) + k\,B(P) B(Rk​)=B(Q)+kB(P)

代入 Pick 定理 → 答案是关于 kkk 的二次多项式，O(1)O(1)O(1) 回答每次询问。

  • 易混淆点：BBB 是格点数，不是边长（虽然放边长上去依然成立）

    • B(A+B)=B(A)+B(B)B(A+B) = B(A) + B(B)B(A+B)=B(A)+B(B) 成立，靠的不是"长度可加"，而是：
      • 不同向的边各自保留，贡献不变。
      • 同向边合并时，gcd⁡\gcdgcd 恰好可加

  • 计算流程

    1. 对 PPP、QQQ 求凸包。
    2. 算 S(Q),  B(Q),  S(P),  B(P)S(Q),\; B(Q),\; S(P),\; B(P)S(Q),B(Q),S(P),B(P)。
    3. 求一次 Minkowski 和 R1=Q+(−P)R_1 = Q + (-P)R1​=Q+(−P)（极角归并，O(n)O(n)O(n)）。
    4. 算 S(R1)S(R_1)S(R1​)，得 C=S(R1)−S(Q)−S(P)C = S(R_1) - S(Q) - S(P)C=S(R1​)−S(Q)−S(P)。
    5. 每次询问代入多项式，模 998244353998244353998244353。

面积为什么是 S(Q)+k2S(P)+kCS(Q) + k^2 S(P) + kCS(Q)+k2S(P)+kC？（最抽象）

你拿 QQQ 沿着 −kP-kP−kP 滑一圈，扫出来的面积，直觉上分三块：

部分 来源 为什么
S(Q)S(Q)S(Q) QQQ 自己的面积 起点那块
k2S(P)k^2 S(P)k2S(P) −kP-kP−kP 自己的面积 PPP 放大 kkk 倍，面积变 k2k^2k2 倍（二维）
kCkCkC 两者"混合"出来的面积 滑动过程中，QQQ 的边和 PPP 的边"交叉"扫出来的，跟 kkk 成正比（一维×一维）

CCC 就是个常数，代表 QQQ 和 PPP 的形状有多"不搭"。你只需要算一次 R1R_1R1​（k=1k=1k=1 的情况），反推出 CCC 就行了。

边界格点为什么是 B(Q)+k⋅B(P)B(Q) + k \cdot B(P)B(Q)+k⋅B(P)？（可以理解）

Minkowski 和的边界 = 把两个多边形的边向量按方向排好序，拼起来。

  • QQQ 的边：原封不动贡献 B(Q)B(Q)B(Q) 个格点。
  • −kP-kP−kP 的边：每条边放大了 kkk 倍。一条边上有 gcd⁡(Δx,Δy)\gcd(\Delta x, \Delta y)gcd(Δx,Δy) 个格点，放大 kkk 倍后变成 gcd⁡(kΔx,kΔy)=k⋅gcd⁡(Δx,Δy)\gcd(k\Delta x, k\Delta y) = k \cdot \gcd(\Delta x, \Delta y)gcd(kΔx,kΔy)=k⋅gcd(Δx,Δy)。

所以 −kP-kP−kP 的边界格点就是 k⋅B(P)k \cdot B(P)k⋅B(P)，加起来就完事了。

Code

#include<bits/stdc++.h>
using namespace std;
using LL = long long;
using LLL = __int128;

const int N = 2e5 + 5;
const LL mod = 998244353, inv2 = (mod + 1) / 2;

struct Vec;

struct Vec{
    LL x,y;
    double angle;
    Vec(LL x=0,LL y=0):x(x),y(y){
        angle = atan2(y, x);
    }
    Vec operator+(Vec o) const { return Vec(x+o.x,y+o.y);}
    Vec& operator+=(Vec o) { x+=o.x; y+=o.y; return *this;}
    Vec operator-(Vec o) const { return Vec(x-o.x,y-o.y);}
    Vec operator-() const { return Vec(-x,-y);}
    Vec operator*(LL k) const { return Vec(x*k,y*k);}
    LLL operator%(Vec o) const { 
        return (LLL)x*o.y - (LLL)y*o.x;
    }
    // 【坑点2：极角排序需要使用极角】
    bool operator<(const Vec& o) const {
        // return *this % o > 0;
        return angle < o.angle;
    }
    friend istream& operator>>(istream& in, Vec& o) {
        return in >> o.x >> o.y;
    }
    friend ostream& operator<<(ostream& os, Vec& o) {
        return os << "Vec:" << o.x << ", " << o.y;
    } 
};

int n, m, q;
int cnt;
Vec P[N], Q[N], C[N*2], R[N*2], tmp[N];
LL sk[3], bk[2];

// 【坑点1：[-1e9, 1e9] 算面积二倍要开 i128 】
LLL S2(Vec* A, int n) {
    LLL res = 0;
    for(int i = 1;i<=n;i++) res += A[i+1] % A[i];
    return res < 0 ? -res:res;
}

// 【坑点3：闵可夫斯基和 + Andrew 都建议传入 1..n 并使用 1..n+1 并返回 B[1..n]】
void minkowski(Vec* A, int n, Vec* B) {
    sort(A+1,A+1+n);
    B[1] = {0,0};
    for(int i = 2; i<=n+1;i++) {
        B[i] = B[i-1] + A[i-1];
        // cout << A[i-1] << "!\n";
    } 
    // for(int i = 1;i<=n+1;i++) {
    //     cout << B[i] << "\n";
    // }
}

int Andrew(Vec* A, int n,Vec* B) {
    sort(A+1,A+1+n,[](Vec& a,Vec& b){
        return a.x != b.x ? a.x < b.x: a.y < b.y;
    });
    int tp = 0;
    for (int i = 1;i <= n;i++) {
        while(tp >= 2 && (B[tp]- B[tp-1]) % (A[i] - B[tp]) <= 0) tp--;
        B[++tp] = A[i];
    }
    int tp2 = tp;
    for(int i = n;i>=1;i--) {
        while(tp2 >= tp + 1 && (B[tp2]-B[tp2-1]) % (A[i] - B[tp2]) <= 0) tp2--;
        B[++tp2] = A[i];
    }
    return tp2-1;
}

void solve() {
    cin >> n >> m >> q;
    cnt = 0;
    for(int i = 1; i <= n; i++) cin >> P[i];
    for(int i = 1; i <= m; i++) cin >> Q[i];

    n = Andrew(P, n, tmp);
    memcpy(P, tmp, sizeof(Vec) * (n+1));
    P[n+1] = P[1];
    m = Andrew(Q, m, tmp);
    memcpy(Q, tmp, sizeof(Vec) * (m+1));
    Q[m+1] = Q[1];
    
    // for(int i = 1; i <= n;i++) cout << P[i] << "!!\n";
    // for(int i = 1; i <= m;i++) cout << Q[i] << "!!!\n";
    
    for(int i = 1;i<=n;i++) C[++cnt] = P[i] - P[i+1];
    for(int i = 1;i<=m;i++) C[++cnt] = Q[i+1] - Q[i];
    minkowski(C, cnt, R);
    sk[2] = S2(P, n) % mod;
    sk[1] = ((S2(R, cnt) - S2(P, n) - S2(Q, m)) % mod + mod) % mod;
    sk[0] = S2(Q, m) % mod;
    for(int i = 1;i<=n;i++) {
        Vec D = P[i+1] - P[i];
        (bk[1] += gcd(abs(D.x), abs(D.y))) %= mod;
    }
    for(int i = 1;i<=m;i++) {
        Vec D = Q[i+1] - Q[i];
        (bk[0] += gcd(abs(D.x), abs(D.y))) %= mod;
    }
    while(q--) {
        LL k;
        cin >> k;
        // 【坑点4：开门爆】
        k %= mod;
        LL res = (
            sk[0]+sk[1]*k%mod+sk[2]*k%mod*k%mod 
            + bk[0] + bk[1] * k % mod + 2
        ) % mod * inv2 % mod;
        cout << res << "\n";
    }
}

int main() {
    // cout << "啥阴（闵可夫斯基和之后的面积爆了）：" << ((4e9 * 4e9 * 2) > LONG_LONG_MAX) << "\n";
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);
    int T = 1;
    // cin >> T;
    while (T--) solve();
}

C 数字游戏

Problem Description

  • Input file: standard input
  • Output file: standard output
  • Time limit: 1 second
  • Memory limit: 256 megabytes

给定一个正整数进制 BBB。

你需要构造三个长度为 BBB 的排列 P,Q,RP, Q, RP,Q,R（即每个序列恰好包含 000 到 B−1B-1B−1 每个数字一次）。

P=(p1,p2,…,pB),Q=(q1,q2,…,qB),R=(r1,r2,…,rB).P = (p_1, p_2, \dots, p_B),\quad Q = (q_1, q_2, \dots, q_B),\quad R = (r_1, r_2, \dots, r_B). P=(p1​,p2​,…,pB​),Q=(q1​,q2​,…,qB​),R=(r1​,r2​,…,rB​).

定义一个序列 X=(x1,x2,…,xB)X = (x_1, x_2, \dots, x_B)X=(x1​,x2​,…,xB​) 在 BBB 进制下表示的整数为

[X]B=∑i=1Bxi⋅BB−i.[X]_B = \sum_{i=1}^{B} x_i \cdot B^{B-i}. [X]B​=i=1∑B​xi​⋅BB−i.

注意序列允许以数字 000 开头，因此表示的整数可以小于 BB−1B^{B-1}BB−1。

请你构造三个排列 P,Q,RP, Q, RP,Q,R，使得它们满足等式（注意加法是在 BBB 进制下的加法）

[P]B+[Q]B=[R]B,[P]_B + [Q]_B = [R]_B, [P]B​+[Q]B​=[R]B​,

并且对于每个位置 iii（1≤i≤B1 \le i \le B1≤i≤B），pi,qi,rip_i, q_i, r_ipi​,qi​,ri​ 两两不同。

如果不存在这样的构造，请输出 −1-1−1。

Input

输入仅一行，包含一个整数 BBB（2≤B≤1062 \le B \le 10^62≤B≤106）。

Output

如果存在合法构造，则输出三行，每行 BBB 个整数，分别表示序列 P,Q,RP, Q, RP,Q,R 中的数字，数字之间用空格分隔。

如果不存在合法构造，则输出一行 −1-1−1。

若存在多种构造，输出任意一种即可。

Sample Input

样例 1：

5

样例 2：

6

Sample Output

样例 1：

-1

样例 2：

4 2 5 0 3 1
0 4 1 2 5 3
5 1 0 3 2 4

Hint

2≤B≤1062 \le B \le 10^62≤B≤106。

Solution

数学场典型计算方式：

  • 整体求和得到不变量性质
    • 即 将每一位的 ai+bi+carrayi=ci+carryi+1×Ba_i + b_i + \text{carray}_i = c_i + \text{carry}_{i+1} \times Bai​+bi​+carrayi​=ci​+carryi+1​×B 求和
    • 再利用天然整除约束得出约束条件
  • 奇偶数重排的加法性质
    • 奇数+奇数=偶数集+进位
    • 偶数+偶数=偶数集+进位
    • 由此通过偶数+进位可得奇数集
  • 循环移位后加法的进位性质
    • 很有规律，天然规律

Code

#include<bits/stdc++.h>
using namespace std;

const int N = 1e6 + 5;

int n;

void solve() {
    cin >> n;
    // cout << n << "\n";
    if ((n&1) || n == 2) cout << -1 << "\n";
    else if(n == 4){
        cout << "1 3 0 2\n0 1 2 3\n2 0 3 1\n";
    } else {
        vector<vector<array<int,3>>> nom(n),pls(n);
        for(int i = 0;i<n;i+=2) {
            int a = i, b = (i - 2 + n) % n;
            int c = (a + b) % n, car = (a + b) / n;
            if (car) {
                pls[c].push_back({a, b, c});
            } else {
                nom[c].push_back({a, b, c});
            }
        }
        for(int i = 1;i<n;i+=2) {
            int a = i, b = (i - 2 + n) % n;
            int c = (a + b) % n, car = (a + b) / n;
            if (car) {
                pls[c].push_back({a, b, c});
            } else {
                nom[c].push_back({a, b, c});
            }
        }
        vector<array<int,3>> ans(n);
        int i = 0;
        assert(nom[n-2].size()==2);
        assert(pls[0].size()==2);
        ans[i++] = nom[n-2][1];
        nom[n-2][0][2]++;
        ans[i++] = nom[n-2][0];
        pls[0][0][2]++;
        ans[i++] = pls[0][0];
        ans[i++] = pls[0][1];
        for(int j = 2;j<n-2;j+=2) {
            assert(nom[j].size() == 1);
            assert(pls[j].size() == 1);
            nom[j][0][2]++;
            ans[i++] = nom[j][0];
            ans[i++] = pls[j][0];
        }
        for(int i = 2;i<n;i+=2) {
            if(ans[i][0] == ans[i][2] || ans[i][1] == ans[i][2]) {
                swap(ans[i], ans[i+1]);
                swap(ans[i][2], ans[i+1][2]);
            }
        }
        for(int j =0;j<3;j++) {
            for(int i = 0;i<n;i++) {
                cout << ans[i][j] << " ";
            }cout << "\n";
        }
    }
}

int main() {
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);
    int T = 1;
    // cin >> T;
    while (T--) solve();
}
