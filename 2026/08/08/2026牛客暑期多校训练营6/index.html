Problem Description

给定两个长度为 nnn 且由正整数组成的数组 aaa 和 bbb。你需要回答 qqq 个以下三种类型的询问：

  • 1 i x1\ i\ x1 i x（1≤i≤n1 \le i \le n1≤i≤n，1≤x≤1091 \le x \le 10^91≤x≤109）：赋值 ai←xa_i \leftarrow xai​←x；
  • 2 i x2\ i\ x2 i x（1≤i≤n1 \le i \le n1≤i≤n，1≤x≤1091 \le x \le 10^91≤x≤109）：赋值 bi←xb_i \leftarrow xbi​←x；
  • 3 l r3\ l\ r3 l r（1≤l<r≤n1 \le l < r \le n1≤l<r≤n）：计算：

max⁡l≤i<j≤rai+ajbi+bj\max_{l \le i < j \le r} \frac{a_i + a_j}{b_i + b_j} l≤i<j≤rmax​bi​+bj​ai​+aj​​

所有的询问将按给出的顺序依次处理。每次赋值操作都会永久修改对应的数组元素，并影响所有后续的询问。

Input

每个测试点的第一行包含两个整数 nnn 和 qqq（2≤n≤1052 \le n \le 10^52≤n≤105，1≤q≤1051 \le q \le 10^51≤q≤105），分别表示数组 aaa 和 bbb 的长度以及询问的数量。

第二行包含 nnn 个整数 a1,a2,…,ana_1, a_2, \ldots, a_na1​,a2​,…,an​（1≤ai≤1091 \le a_i \le 10^91≤ai​≤109），表示数组 aaa 的元素。

第三行包含 nnn 个整数 b1,b2,…,bnb_1, b_2, \ldots, b_nb1​,b2​,…,bn​（1≤bi≤1091 \le b_i \le 10^91≤bi​≤109），表示数组 bbb 的元素。

接下来的 qqq 行，每行包含一个询问。

Output

对于每个第三种类型的询问，可以证明其答案能被唯一表示为最简分数 xy\frac{x}{y}yx​。你需要输出两个整数 xxx 和 yyy。
