每只宝可梦通过终点的时间均不相同。因此，它们的完赛名次构成 1,2,…,x+y+z1, 2, \ldots, x + y + z1,2,…,x+y+z 的一个排列，其中名次 111 表示最先完赛。

J Leaf Order Reconstruction

Problem Description

在无数次试图拯救 Madoka 之后，Homura Akemi 已经体验了许多不同的时间线。

Kyubey 将这些因果关系表示为一棵有 nnn 个顶点的树，以顶点 111 为根。根代表所有时间循环的共同起点，每条边代表时间线之间的一次分歧。

顶点的深度定义为从根到该顶点路径上的边数。没有子顶点的顶点称为叶子，代表一个已完成的时间线。

Homura 恰好体验了每个已完成的时间线一次，体验顺序未知，记为 L1,L2,…,LsL_1, L_2, \ldots, L_sL1​,L2​,…,Ls​。

Kyubey 的观测系统按如下规则为每个叶子 uuu 保存一个参考编号 bub_ubu​：

  • 第一个被体验的叶子被赋予参考编号 000。
  • 对于之后每个叶子 uuu，系统考察所有先前被体验过的叶子，并选择一个叶子 vvv，使得 depth⁡(LCA⁡(u,v))\operatorname{depth}(\operatorname{LCA}(u,v))depth(LCA(u,v)) 尽可能大。
  • 如果有多个叶子满足该条件，则选择其中被体验最早的叶子。
  • 然后系统令 bu=vb_u = vbu​=v。

其中，LCA⁡(u,v)\operatorname{LCA}(u,v)LCA(u,v) 表示树中 uuu 和 vvv 的最近公共祖先。最近公共祖先越深，表示两条时间线共享越长的因果历史。

给定这棵树和所有参考编号，判断它们是否可能由某种 Homura 体验叶子的顺序产生。如果存在这样的顺序，输出任意一种合法顺序。

Input

第一行包含一个整数 nnn（1≤n≤2⋅1051 \le n \le 2 \cdot 10^51≤n≤2⋅105）——树中顶点的数量。

接下来 n−1n-1n−1 行，每行包含两个整数 uuu 和 vvv（1≤u,v≤n1 \le u, v \le n1≤u,v≤n），表示顶点 uuu 和 vvv 之间的一条无向边。保证给出的边构成一棵树。

下一行包含一个整数 sss（1≤s≤n1 \le s \le n1≤s≤n）——当树以顶点 111 为根时叶子的数量。

接下来 sss 行，每行包含两个整数 uuu 和 bub_ubu​（1≤u≤n1 \le u \le n1≤u≤n，0≤bu≤n0 \le b_u \le n0≤bu​≤n），其中 uuu 是一个叶子，bub_ubu​ 是它的参考编号。

保证给出的顶点恰好是根树中的所有叶子，且每个叶子恰好出现一次。

注意，非零值 bub_ubu​ 不保证是某个叶子的编号。

Output

如果不存在合法的叶子访问顺序，输出一行 NO。

否则，第一行输出 YES。第二行输出 sss 个整数 L1,L2,…,LsL_1, L_2, \ldots, L_sL1​,L2​,…,Ls​，表示 Homura 可能体验已完成时间线的一个合法顺序。

每个叶子必须在输出序列中恰好出现一次。

如果存在多个合法顺序，输出任意一个即可。

Hint

在第一个例子中，叶子是 4,5,6,74, 5, 6, 74,5,6,7。考虑顺序 4,5,6,74, 5, 6, 74,5,6,7。

叶子 444 最先被体验，因此 b4=0b_4 = 0b4​=0。

对于叶子 555，先前唯一被体验过的叶子是 444，因此 b5=4b_5 = 4b5​=4。

对于叶子 666，444 和 555 与 666 的最近公共祖先相同。由于 444 被体验得更早，系统令 b6=4b_6 = 4b6​=4。

对于叶子 777，有 LCA⁡(7,6)=3\operatorname{LCA}(7,6)=3LCA(7,6)=3，而 LCA⁡(7,4)=LCA⁡(7,5)=1\operatorname{LCA}(7,4)=\operatorname{LCA}(7,5)=1LCA(7,4)=LCA(7,5)=1。由于顶点 333 比顶点 111 更深，系统令 b7=6b_7 = 6b7​=6。

因此，4,5,6,74, 5, 6, 74,5,6,7 是一个合法顺序。
