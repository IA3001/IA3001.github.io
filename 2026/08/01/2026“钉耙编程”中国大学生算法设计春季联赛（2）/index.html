1003 A 和 B 依次选数 选完后立刻删除该数

Problem Description

有一个长度为 nnn 的序列 aaa，f(k)f(k)f(k) 为以下循环后最终 A 可以获得的最大值：

  • A 先手拿走任意一个 aaa 中剩余的数字
  • B 后手拿走 aaa 中前 kkk 个数字

对于 k=1,2,…,n−1k = 1, 2, \dots, n-1k=1,2,…,n−1 求 f(k)f(k)f(k)。

数据范围：2≤n≤2×1052 \le n \le 2 \times 10^52≤n≤2×105，1≤ai≤1091 \le a_i \le 10^91≤ai​≤109

Solution

限制转化、调和级数、（可撤销）单点修改线段树 /（可撤销）快速删除数组

先看这个单人博弈是怎么转化的：

  • 首先可以知道：前 k+1k+1k+1 个数最多只能选 1 个，前 2k+22k+22k+2 个数最多选 2 个……
  • A 最终选择了 num=⌈n/(k+1)⌉\text{num} = \lceil n / (k+1) \rceilnum=⌈n/(k+1)⌉ 个数（调和级数已经出现了！！！）
  • 所以什么意思呢？画个图
  • 你会发现可以使用 num\text{num}num 个后缀区间即可转化为：只能使用这 num\text{num}num 个区间来获取数字，最终的最大值

显然决策可以这样做：

  • 因为最左边的自由度最大，所以最后决策
  • 从右往左决策，每次取当前后缀集合中元素的最大值即可！
  • 决策多少次？O(num)=O(n/k)O(\text{num}) = O(n/k)O(num)=O(n/k)，调和级数！！！

决策所需要的数据结构要求是什么样的？

  • 需要在一个数组中区间查询最大值
  • 需要在一个数组中单点删除
    • 什么？删除？难道是集合、堆的操作？？？
    • 不！！！线段树也可以删除！
    • 什么是线段树的删除？
      • 删除就是让这个元素成为答案的优先级最小！！！（即等价于修改操作！！！）
    • 线段树既然可以删除，如何复原？
      • 用一个栈维护，不久实现带撤销了吗！！！
  • 当时莫名觉得线段树节点维护单个区间 max⁡\maxmax 值有点诡异

快速删除数组的基本 Trick：

  • 往往要查询区间最值
  • 在删除最值的时候可能有多个，若要只删除最左/最右的一个
  • 所以往往需要增加一维 index，即 pair<T, int> 作为线段树节点值

        if(p<=mid)insert(i*2,l,mid,p);

        up(i);
    }
}
// 删除 索引
void erase(int i,int l,int r,int p) {
    if(l==r){
        S[i] = {0,0};
    }else {
        int mid = (l+r)/2;
        if(p<=mid)erase(i*2,l,mid,p);
        else erase(i*2+1,mid+1,r,p);
        up(i);
    }
}
