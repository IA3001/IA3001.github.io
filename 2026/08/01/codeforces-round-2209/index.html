D RGB三色限制序列构造

Problem Description

（赛时未做）给出 R,G,BR,G,BR,G,B 三种字符的数量，构造尽可能长的序列满足：

  • S[i]≠S[i−1]S[i] \ne S[i-1]S[i]=S[i−1]
  • S[i]≠S[i−3]S[i] \ne S[i-3]S[i]=S[i−3]

Solution

构造、贪心

贪心构造需要引理：

  • 构造串一定可以通过拼接若干个双字符对（RG、GB、RB 等）加上最多一个单字符
  • 构造串翻转后仍然合法，因此可以先添加单个字符
  • 间隔一格使用相同字符是可以利用的
  • 根据鸽巢原理和进一步证明，发现如果每种字符的占比不超过 ⌈S/2⌉\lceil S/2 \rceil⌈S/2⌉，一定可以用完所有的字符（相当于配对充分，最多剩下单个字符）

贪心即是维持平衡：

  • 利用贪心策略（优先使用剩下的最多的）动态抹平各颜色的数量差，始终保持引理成立

E 字符串最大前缀分解数

Problem Description

设 f(s)f(s)f(s) 为字符串 sss 分解为若干个 sss 前缀的最大分解数。

给定 sss，如何 O(n)O(n)O(n) 求解 ∑i=1nf(s[1…i])\sum_{i=1}^n f(s[1 \dots i])∑i=1n​f(s[1…i])？

Solution

KMP + 最小 border

记住这个结论：字符串的最大前缀分解数量，其方案为不断截取它尾部的最小 border 得到的分解。

Code

vector<int> getNe(const string& s){
    int n=s.length();
    vector<int> ne(n);
    for(int i=1,j=0;i<n;i++){
        while(j&&s[i]!=s[j])j=ne[j-1];
        if(s[i]==s[j])j++;
        ne[i]=j;
    }
    // 最小 border 的求解: 不断跳的传递 
    for(int i=1;i<n;i++)
        // 要减个 1 啊！ 因为它是 0-base 的而 ne[i] 的含义是长度 所以要 -1
        if(ne[i]&&ne[ne[i]-1])ne[i]=ne[ne[i]-1];
    return ne;
}

F Dynamic Values And Maximum Sum

Problem Description

给定一棵 nnn 节点的树，点权为 1≤a[i]≤1091 \le a[i] \le 10^91≤a[i]≤109。

定义一次操作为：

  • 选择一个点作为树的根
  • 分数加等于它的点权，然后它的点权变为 000
  • 这个有根树的所有非叶节点 iii 均将自己的权值加到自己的子树中第一关键字距离最大、第二关键字编号最小的那个节点 d[i]d[i]d[i]，然后自己变为 000

最多进行 kkk 次操作，求最终的分数最大值。

Solution

树形 DP、换根 DP、动态 k 大值数据结构

显然，一旦进行一次操作，所有的点权都会集中到叶子上，以后不再迁移。

所以很自然就想到：

  • 树形 DP + 换根 DP + 查询剩余树上前 k−1k-1k−1 大的和
    • 树形 DP 用于预处理 1 为根情况的答案以及初始的 d[i]d[i]d[i]
    • 换根 DP 的内容（遍历相邻节点 vvv，从 uuu 换到 vvv）
      • 原先 uuu 从没有对叶子的贡献，变为有向"父子树"中的某个叶子的贡献
        • 如果 d[u]d[u]d[u] 与 d[v]d[v]d[v] 相同，说明 uuu 来自 vvv，需要选取次大的 d[u]d[u]d[u]
        • 如果没有次大的 d[u]d[u]d[u]，说明 uuu 之后会变成叶子（新的叶子出现了）
      • 原先 vvv 从有对"子树"中的某个叶子的贡献，变为没有对叶子的贡献
        • 注意：vvv 即将成为根，所以 vvv 需要计算它为根的最大/次大 d[v]d[v]d[v]
        • uuu 是它的一个新的子树，自然 vvv 需要按照预处理时的方式，用最大 d[u]d[u]d[u] 更新 d[v]d[v]d[v]
        • 特别的，如果 vvv 之前已经是叶子了，那么 vvv 只会有最大 d[v]d[v]d[v]（叶子消失了）
        • 现在 vvv 为根所需要的信息都已经齐全，计算 ans[v]\text{ans}[v]ans[v] 并向下推 dfs2(v,u)
        • 重置1：回溯 vvv 的贡献，恢复 vvv 不为根时向"子树"中某个叶子的贡献
      • 重置2：回溯 uuu 关于这个 vvv 的贡献，撤回 uuu 向"父子树"中的某个叶子的贡献
