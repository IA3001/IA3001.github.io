1003 通行证（Hard Version）

Problem Description

给定 n×nn \times nn×n 方阵 aaa，外围 4n+44n+44n+4 个人构成 (n+2)×(n+2)(n+2) \times (n+2)(n+2)×(n+2) 的方阵 bbb。ai,ja_{i,j}ai,j​ 为 aaa 中第 iii 行第 jjj 列的识别码，bbb 中其余人的识别码均为 1010010^{100}10100。

对于通行证 card\text{card}card，识别码 xxx 满足 (x∣card)≠card(x \mid \text{card}) \ne \text{card}(x∣card)=card 的人为坏蛋。aaa 中每个人从上下左右四个方向检查途径的人（含自身），该方向最近坏蛋与自身的距离为该方向安全感，四个方向的最小值即此人的安全感。求 aaa 中所有人的安全感之和。

数据范围：1≤T≤21 \le T \le 21≤T≤2，1≤n≤15001 \le n \le 15001≤n≤1500，1≤q≤5×1041 \le q \le 5 \times 10^41≤q≤5×104，0≤ai,j<2150 \le a_{i,j} < 2^{15}0≤ai,j​<215，0≤card<1090 \le \text{card} < 10^90≤card<109。

Solution

SOS 高维前缀和、答案差分化、short

  • 要看看对于某一个人来说，card\text{card}card 在什么情况下才可以延伸 0,1,2,3,…,n0, 1, 2, 3, \dots, n0,1,2,3,…,n 格
  • 发现这种 card\text{card}card 具有集合的运算包含性质，所以对于每一种四方向前缀或和，在对应的 mask 状态 ++
  • （Hard Version O(n3)O(n^3)O(n3) 有点大）发现对于一个前缀或和来说，最多变化 log 次，所以只需要记录一个地方上的上下左右的下一个第 bbb 位的 111 在哪一行/列

踩坑

  • TLE：即使 Easy Version 如果直接暴力 TLE
  • WA：debug 的时候改小了常量，直接 TM 找不到错误了，以为对了，其实错了，把我整懵了
  • WA：取多次 min 的时候 mn = min({,,,}) 里面啥都写了，就是没写 mn
  • MLE：这个信息有点稍微大，不开 short 就 MLE 了！第一次见 short 优化 MLE！

Code

for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= n; j++) {
        int msk = a[i][j];
        int d = 0;
        while(d <= n) {
            if(i - d >= 1 && i + d <= n && j - d >= 1 && j + d <= n) {
                int mn = 1e9;
                for (int b = 0; b < M; b++) {
                    if (msk >> b & 1) continue;
                    mn = min({
                        mn, // !!!!
                        i - U[i-d][j][b],
                        D[i+d][j][b] - i,
                        j - L[i][j-d][b],
                        R[i][j+d][b] - j
                    });
                }
                int tmp;
                if(mn == 1e9) {
                    f[msk] += (tmp = min({
                        i - d, j - d,
                        n + 1 - i - d,
                        n + 1 - j - d  
                    }));
                } else {
                    f[msk] += (tmp = mn - d);
                    msk |= a[i-mn][j] | a[i+mn][j] | a[i][j-mn] | a[i][j+mn];
                }
                d = mn;
            } else break;
        }
    }
}
