Kevin的矩阵

Problem Description

给定一个长度为 nnn 的数组，初始时排列在一个 mmm 列的表格中，你可以 ++m++m++m、−−m--m−−m 或者改变一个元素的值，问将某一列的元素全部变为 kkk 的最小操作次数是多少。

数据范围：1≤n≤2×1051 \le n \le 2 \times 10^51≤n≤2×105

Solution

复杂度诈骗、暴力剪枝

  • 因为总个数有限，ans=O(Δ+cnt)=O(Δ+n/(m±Δ))\text{ans} = O(\Delta + \text{cnt}) = O(\Delta + n / (m \pm \Delta))ans=O(Δ+cnt)=O(Δ+n/(m±Δ))
  • 因为移动 O(n)O(\sqrt{n})O(n​) 次列长度就必然收敛到 O(n)O(\sqrt{n})O(n​) 级别了
