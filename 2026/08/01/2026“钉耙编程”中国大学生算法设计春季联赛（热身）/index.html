1001 最大的公约数

Problem Description

给定一个正整数 nnn，找到两个正整数 aaa 和 bbb，满足：

  • a+b=na + b = na+b=n
  • a>ba > ba>b
  • 使得 gcd⁡(a,b)\gcd(a, b)gcd(a,b) 的值最大

输出这个最大的 gcd⁡(a,b)\gcd(a, b)gcd(a,b)。

Solution

GCD

gcd 性质：gcd⁡(a,b)=gcd⁡(a,n−a)=gcd⁡(a,n)\gcd(a,b) = \gcd(a,n-a) = \gcd(a,n)gcd(a,b)=gcd(a,n−a)=gcd(a,n)

注意特判：a≠ba \ne ba=b

1002 雪蜜冰城柠檬茶的神秘成分魔法

Problem Description

柠檬茶配方中有一个整数数列，支持以下三种操作：

  • 操作 1 xxx yyy：将数列中所有等于 xxx 的元素替换为 yyy。
  • 操作 2 xxx：在数列末尾添加一个 xxx。
  • 操作 3 xxx：删除数列中所有等于 xxx 的元素。

多组数据，数据范围：
1≤t≤101 \le t \le 101≤t≤10，1≤n≤2×1051 \le n \le 2 \times 10^51≤n≤2×105，1≤m≤1051 \le m \le 10^51≤m≤105，1≤ai≤1071 \le a_i \le 10^71≤ai​≤107，1≤x,y≤1071 \le x, y \le 10^71≤x,y≤107

Solution

启发式合并（O(nlog⁡n)O(n \log n)O(nlogn)）

亮点：使用 stk[] 按需存储，灵活清空数据

if(op==1){

另解（正解）：正难则反（O(n)O(n)O(n)）

想一想：一个元素它最终的值取决于什么？

  • 一旦一个元素被添加，它最终的值等于后续操作的映射值
  • 考虑多次映射 x→y→zx \to y \to zx→y→z，这是满足传递性的

所以倒序处理元素：

  • 初始化 f[x]=x（f[x] 是直接映射，不压缩）；最后添加的元素一定是未被重定向的
  • 1 x y：f[x]=f[y]，在这之前裸的 xxx 值都变为裸的 yyy 之后的直接映射
  • 2 x：如果 if(f[x]) ans.push_back(f[x])，查询裸的 xxx 最终值
  • 3 x：f[x]=0，之前的裸的 xxx 值不再需要
  • 倒序输出 ans

1005 时空碎片收集者

Problem Description

在一条从 111 到 nnn 的路径上有 nnn 个节点，第 iii 个节点有基础碎片 aia_iai​。收集者从节点 111 进入，走到大于 nnn 的节点即离开。他需要在每个节点选择以下三种操作之一：

  • 直接收集：获得 aia_iai​ 碎片，然后进入节点 i+1i+1i+1。
  • 时空回溯：获得 2ai2a_i2ai​ 碎片，但会使接下来 kkk 个节点（i+1i+1i+1 到 i+ki+ki+k）的碎片变为原来的一半（向下取整），且这些节点不能再使用时空回溯（回溯效果不可叠加）。然后进入节点 i+1i+1i+1。
  • 时空跳跃：获得从节点 iii 到 i+mi+mi+m 的所有碎片（即 ai+ai+1+⋯+ai+ma_i + a_{i+1} + \dots + a_{i+m}ai​+ai+1​+⋯+ai+m​），然后进入节点 i+m+1i+m+1i+m+1。跳跃获得的碎片始终取原始值，不受回溯影响。

求能收集到的最大碎片总数。

输入包含 ttt 组数据，1≤t≤101 \le t \le 101≤t≤10。每组数据第一行三个整数 n,k,mn, k, mn,k,m，满足 1≤n≤1051 \le n \le 10^51≤n≤105，1≤k≤251 \le k \le 251≤k≤25，1≤m≤501 \le m \le 501≤m≤50；第二行 nnn 个整数 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​，满足 1≤ai≤1051 \le a_i \le 10^51≤ai​≤105。所有组的 nnn 之和不超过 2×1062 \times 10^62×106。

正推贡献DP

显然又看到了小值域 k,mk,mk,m 可以 dp，本题巧妙地将区间范围影响转化为了 buff 剩余回合数量。

注意 dp 转移正难则反：要么使用逆推溯源法，要么使用正推贡献法（本题）。

1006 光辉岁月

Problem Description

水圣人活了 nnn 年，每年有一个约定，用数组 aia_iai​ 表示是否记得第 iii 年的约定（000 表示不记得，111 表示记得）。小 www 施展 qqq 次魔法，每次魔法使一段连续年份 [l,r][l, r][l,r] 间的所有约定被想起（即永久变为记得）。

每次魔法后，小 www 任意挑选一段年份 [L,R][L, R][L,R]（1≤L≤R≤n1 \le L \le R \le n1≤L≤R≤n），记录这段区间内所有可以想起的约定的年份，得到 ttt 个年份。如果 t=1t = 1t=1 或存在 k≥1k \ge 1k≥1 使得这些年份构成公差为 kkk 的等差数列，那么这段岁月 [L,R][L, R][L,R] 称为光辉岁月。对于每次魔法，求所有光辉岁月中最大的 ttt。

数据范围：TTT 组测试，1≤T≤1031 \le T \le 10^31≤T≤103，每组 n,qn, qn,q 满足 ∑n≤2×105\sum n \le 2 \times 10^5∑n≤2×105，∑q≤2×105\sum q \le 2 \times 10^5∑q≤2×105，数组元素为 000 或 111，每次魔法的 l,rl, rl,r 满足 1≤l≤r≤n1 \le l \le r \le n1≤l≤r≤n。

Solution

线段树区间信息合并

注意到等差数列，因此想到维护最长连续序列。

亮点：

  • 使用集合 val 缓存未出现的值
  • 使用 pre 维护前驱，寻找后继

踩坑

  • UNK、WA：线段树区间信息合并不熟练
    • 两处（up 和 query）都要写全信息、写对合并 case

Code

struct SegmentTree{
    int f[N*4];
    int L[N*4],R[N*4];
    int lc[N*4],rc[N*4];
    int md[N*4],len[N*4];
    void up(int i){
        int l=i*2,r=i*2+1;
        len[i]=len[l]+len[r];
        L[i]=L[l]?L[l]:L[r];
        R[i]=R[r]?R[r]:R[l];
        lc[i]=lc[l]?lc[l]:lc[r];
        rc[i]=rc[r]?rc[r]:rc[l];
        md[i]=max({md[l],md[r],rc[l],lc[r]});
        if(R[l]&&L[r]&&R[l]==L[r]){
            md[i]=max(md[i],rc[l]+lc[r]);
            if(lc[l]==len[l])lc[i]=len[l]+lc[r];
            if(rc[r]==len[r])rc[i]=len[r]+rc[l];
        }
    }
    void build(int i,int l,int r){
        if(l==r){
            L[i]=R[i]=0;
            lc[i]=rc[i]=md[i]=0;
            len[i]=0;
        }else {
            int mid=(l+r)/2;
            build(i*2,l,mid);
            build(i*2+1,mid+1,r);
        }
    }
    void modify(int i,int l,int r,int p,int v){
        if(l==r){
            L[i]=R[i]=v;
            len[i]=md[i]=v>0;
            lc[i]=rc[i]=v>0;
        }else {
            int mid=(l+r)/2;
            if(p<=mid)modify(i*2,l,mid,p,v);
            else modify(i*2+1,mid+1,r,p,v);
            up(i);
        }
    }
    array<int,6> query(int i,int l,int r,int jl,int jr){
        if(jl<=l&&r<=jr){
            return {L[i],R[i],lc[i],rc[i],md[i],len[i]};
        }else {
            int mid=(l+r)/2;
            if(jl<=mid&&jr>=mid+1){
                auto [lL,lR,llc,lrc,lmd,llen] = query(i*2,l,mid,jl,jr);
                auto [rL,rR,rlc,rrc,rmd,rlen] = query(i*2+1,mid+1,r,jl,jr);
                int mL,mR,mlc,mrc,mmd,mlen;
                mlen=llen+rlen;
                mL=lL?lL:rL;
                mR=rR?rR:lR;
                mlc=llc?llc:rlc;
                mrc=rrc?rrc:lrc;
                mmd=max({lmd,rmd,lrc,rlc});
                if(lR&&rL&&lR==rL){
                    mmd=max(mmd,lrc+rlc);
                    if(llc==llen)mlc=llen+rlc;
                    if(rrc==rlen)mrc=rlen+lrc;
                }
                return {mL,mR,mlc,mrc,mmd,mlen};
            }else if(jl<=mid) return query(i*2,l,mid,jl,jr);
            else return query(i*2+1,mid+1,r,jl,jr);
        }
    }
}T;

1008 单十一花钱计划

Problem Description

  • 有 TTT 天，每天有 nnn 件衣服，第 jjj 件衣服有两种价格 aja_jaj​ 和 bjb_jbj​。
  • 每天进行 qqq 次购买，第 iii 次购买给定区间 [li,ri][l_i, r_i][li​,ri​] 和两个整数 Xi,YiX_i, Y_iXi​,Yi​。
  • 对于区间内每件衣服 jjj，价格临时变为 aj+xia_j + x_iaj​+xi​ 和 bj+yib_j + y_ibj​+yi​，歪歪选择较低的价格支付，即实际支付 min⁡(aj+xi,bj+yi)\min(a_j + x_i, b_j + y_i)min(aj​+xi​,bj​+yi​)。
  • 她希望买到最贵的衣服，答案为区间内所有 min⁡(aj+xi,bj+yi)\min(a_j + x_i, b_j + y_i)min(aj​+xi​,bj​+yi​) 的最大值。
  • 每次购买后价格恢复原状。
  • 强制在线

数据范围：T≤5×105T \le 5 \times 10^5T≤5×105，n,q≤5×104n, q \le 5 \times 10^4n,q≤5×104，∑ni≤5×105\sum n_i \le 5 \times 10^5∑ni​≤5×105，∑qi≤5×105\sum q_i \le 5 \times 10^5∑qi​≤5×105，ai,bi,Xi,Yi≤109a_i, b_i, X_i, Y_i \le 10^9ai​,bi​,Xi​,Yi​≤109，1≤l≤r≤n1 \le l \le r \le n1≤l≤r≤n。

Solution

分块（O(nnlog⁡n)O(n \sqrt{n} \log n)O(nn​logn)）

注意到两种属性及其操作具有相对性，到达一定的临界点才会转变，所以排序后在差值上面二分即可得到边界。

struct BArray{
    int n,len,bn;
    // 排完序忘了拷贝了 
    array<LL,2> ab[N],tmp[N];
    LL c[N];
    LL pre_maxb[N],suf_maxa[N];
    int id[N];
    int st[B],ed[B];
    void build(){
        len=ceil(sqrt(n));
        bn=(n+len-1)/len;
        for(int i=1;i<=bn;i++){
            st[i]=(i-1)*len+1;
            ed[i]=min(n,st[i]+len-1);
            fill(id+st[i],id+ed[i]+1,i);
        }
        for(int I=1;I<=bn;I++){
            int l=st[I],r=ed[I];
            sort(ab+l,ab+r+1,[](auto a,auto b){
                return a[1]-a[0]<b[1]-b[0];
            });
            for(int i=l;i<=r;i++)c[i]=ab[i][1]-ab[i][0];
            pre_maxb[l]=ab[l][1];// 服了 这里 i 重定义 差点没看出来
            suf_maxa[r]=ab[r][0];// 服了 这里 i 重定义 差点没看出来 
            for(int i=l+1;i<=r;i++)pre_maxb[i]=max(pre_maxb[i-1],ab[i][1]);
            for(int i=r-1;i>=l;i--)suf_maxa[i]=max(suf_maxa[i+1],ab[i][0]);
        }
    }
    LL query(int l,int r,LL x,LL y){
        int L=id[l],R=id[r];
        LL res=0;
        if(L==R){
            for(int i=l;i<=r;i++)res=max(res,min(tmp[i][0]+x,tmp[i][1]+y));
        }else{
            for(int i=l;i<=ed[L];i++)res=max(res,min(tmp[i][0]+x,tmp[i][1]+y));
            for(int I=L+1;I<=R-1;I++){
                int ll=st[I],rr=ed[I];
                int pos=lower_bound(c+ll,c+rr+1,-(y-x))-c;
                if(pos<=rr)res=max(res,suf_maxa[pos]+x);
                if(pos>ll)res=max(res,pre_maxb[pos-1]+y);
            }
            for(int i=st[R];i<=r;i++)res=max(res,min(tmp[i][0]+x,tmp[i][1]+y));
        }
        return res;
    }

void build(int p, int l, int r, const vector<Info> &arr) {
    if (l == r) {
        seg[p].assign(1, arr[l]);
        tree1[p].assign(1, arr[l].a);
        tree2[p].assign(1, arr[l].b);
        return;
    }
    int m = (l + r) >> 1;
    build(p << 1, l, m, arr);
    build(p << 1 | 1, m + 1, r, arr);

    int siz = seg[p << 1].size() + seg[p << 1 | 1].size();
    seg[p].resize(siz);
    merge(seg[p << 1].begin(), seg[p << 1].end(), seg[p << 1 | 1].begin(), seg[p << 1 | 1].end(), seg[p].begin());

    tree1[p].resize(siz);
    tree2[p].resize(siz);

    tree1[p][0] = seg[p][0].a;
    for (int i = 1; i < siz; ++i)
        tree1[p][i] = max(tree1[p][i - 1], seg[p][i].a);

    tree2[p][siz - 1] = seg[p][siz - 1].b;
    for (int i = siz - 2; i >= 0; --i)

}
