扫描线笔记

· 2026-08-01 · 2 千字 · #笔记 #扫描线

扫描线的完整分类

扫描线的核心思想：将高自由度的静态问题，通过离线事件驱动，转化为低自由度的动态一维过程。下面四种类型覆盖了绝大多数经典应用。

类型一：前缀差分式扫描（只加不删）

树状数组、前缀差分

  • 场景：静态点集 / 图形，查询任意矩形区域的覆盖情况。
  • 扫描轴：xxx 坐标。
  • 维护维：yyy 轴，用 BIT 维护单点添加 + 区间前缀和。
  • 事件设计：点出现 → 单点添加事件；询问 → 拆成 (x1−1,−1)(x_1-1, -1)(x1​−1,−1) 和 (x2,+1)(x_2, +1)(x2​,+1) 两个时刻的区间查询。
  • 代表题：圆与矩形相交（中间矩形部分）、二维偏序计数。
  • 核心特点：图形永久存在，无删除操作，BIT 常数极小。

类型二：参数轴扫描（有加有删，贡献随参数变化）

参数枚举、BIT 翻转、离线排序

  • 场景：每个元素的贡献随查询参数 ddd 变化，且变化次数极少。
  • 扫描轴：参数 ddd（或其低比特位等有效区间）。
  • 维护维：序列下标，用 BIT 维护单点翻转/修改 + 区间异或/求和。
  • 事件设计：预拆每个元素的贡献变化点为修改事件；询问按参数排序后挂在对应时刻。
  • 代表题：区间 ai XOR da_i \ \text{XOR} \ dai​ XOR d 求和。
  • 核心特点：利用参数维度的周期性，把复杂贡献拆成少量翻转事件，在参数轴上统一推进。

类型三：区间覆盖式扫描（有加有删，需线段树）

线段树、矩形面积并、周长并

  • 场景：矩形面积并、周长并、覆盖次数等几何度量。
  • 扫描轴：xxx 坐标。
  • 维护维：yyy 轴，用线段树维护区间覆盖次数及聚合信息（如有效长度）。
  • 事件设计：矩形左边界 +1+1+1，右边界 −1-1−1。同坐标时严格规定处理顺序。
  • 代表题：亚特兰蒂斯（矩形面积并）。
  • 核心特点：必须处理区间增减，线段树的懒标记与信息维护是关键。

类型四：序列—时间互换式扫描

历史版本和、懒标记、线段树

  • 场景：对序列进行多次区间修改，询问每个位置在某个时刻的历史状态。
  • 轴选取：将序列下标作为扫描轴，数据结构维护时间维上的贡献。
  • 代表题：区间子区间问题、历史版本和。
  • 核心特点：反转"时间 → 序列"为"序列 → 时间"，一次扫描求出所有位置完整历史。

维护答案的两种方式

对前两种扫描线类型，答案的生成策略有本质区别：

方式 A：主动维护各参数下的答案

  • 特征：扫描线上单独某个时刻的查询结果本身就有意义，不依赖差分。
  • 典型应用：参数轴扫描（区间 XOR 求和）。
  • 做法：扫描轴每推进一单位，先处理该时刻所有修改，直接回答该时刻的所有询问，所得结果即为最终答案的一部分。
  • 原因：BIT 状态完全反映当前参数下的真实贡献，区间查询即可获得正确结果。

方式 B：差分后求区间和式答案

  • 特征：单点查询无意义，必须用两端点的差才能获得有意义答案。
  • 典型应用：前缀差分式扫描（圆与矩形相交）。
  • 做法：询问拆成左右端点（带上相反符号），扫描时遇到查询只将当前 BIT 值乘以符号累加到答案数组，所有事件处理完毕后答案才完整。
  • 原因：BIT 维护"到当前 xxx 为止"的前缀信息，只有 x2x_2x2​ 减去 x1−1x_1-1x1​−1 才是区间内的真实值。

记忆口诀：参数轴直接出答案，坐标轴差分出答案。判断方法：看询问是一个"确定的状态点"还是一个"需要边界的统计区间"。

通用解题流程

解题六步法

  1. 找出"小参数"：半径 ≤30\le 30≤30、值域 <217<2^{17}<217、修改次数 ≤10 等，决定能否枚举或展开。
  2. 建立二维坐标系：确定扫描轴（xxx / 参数 / 序列下标）与维护维。思考查询在原坐标系中的形状，能否用差分简化。
  3. 判定答案类型：查询是独立的"点"还是必须差分的"区间"？决定用方式 A 还是方式 B。
  4. 拆解事件：
    • 修改事件：何时、何位置、什么操作（+1+1+1 / 翻转 / 标记）。
    • 查询事件：挂在什么时刻、什么符号（方式 B 才有 111）。
  5. 选择数据结构：
    • 只加不删 + 前缀查询 → BIT。
    • 有加有删 + 单点修改/翻转 → BIT。
    • 区间覆盖增减 + 聚合信息 → 线段树。
    • 异或维护 → BIT 可做异或前缀。
  6. 排序与执行：按扫描轴升序，同坐标修改优先于查询（除非题目特殊说明）。遍历事件，驱动数据结构，按策略累加答案。

终极武器

你从被扫描线折磨疯，到自己总结出"前缀差分"和"参数轴"两种思路，再到吃透两道神题，提炼出的核心心法：

小规模拆分套扫描线 —— 利用题目的特殊限制（小半径、低位宽、少状态），把复杂结构拆成大量简单事件，再用常数极小的 BIT 离线一次扫完。

结合对"主动出答案 vs 差分出答案"的区分，你已经能够瞬间判别扫描策略和数据结构的选择。

后续只需大量刷题，把建系、拆事件、符号处理变成肌肉记忆。记住：扫描线不是孤立的套路，而是你手中的离线降维引擎。
