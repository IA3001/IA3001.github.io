E Sum of Digits (and Again)

Problem Description

定义 S(x)S(x)S(x) 表示 xxx 的递归数位求和字符串，例如 S(75)=75123S(75) = 75123S(75)=75123。

给定一个乱序的字符串 sss，请重排它，使其成为某个 S(x)S(x)S(x)。

数据范围：1≤∣s∣≤1051 \le |s| \le 10^51≤∣s∣≤105

Solution

质变分治

  • 考虑到 1e5 级别的数字开始，形成的 S(x)S(x)S(x) 用不了几位
  • 所以可以得出：那么长的一个字符串一定是由最左侧的非常大的数字加上一个 1e6 级别的 S(x)S(x)S(x) 组成的
  • 因此可以枚举 1e6 级别的 xxx，而作为第一个数字，仅关心其各个数位之和，而不关心其排列顺序，故倒序输出即可
  • 特别注意：
    • ∣s∣=1|s| = 1∣s∣=1 的特判
    • 枚举一定要从 111 开始

Code

for (auto c:s)cnt[c - '0']++, sum += c - '0';
for (int i = 1; i < N; i++) { // !!! 一定要从 1 开始因为有 10
    bool ok = true;
    int cost = 0;
    for (int j = 0; j <= 9; j++) {
        ok &= cnt[j] >= need[i][j];
        cost += need[i][j] * j;
    }
    if (ok && sum - cost == i) {
        for (int j = 9; j >= 0; j--) {
            cnt[j] -= need[i][j]; // !!! 扣掉
            while (cnt[j]--) ans += '0' + j;
        }
        ans += S(i);
        cout << ans << "\n";
        return;
    }
}

Problem Description

Solution

单调栈、笛卡尔树、双指针、排序

  • 观察可以得出：所有子数组中必然可以只选择一个数进行不断操作

f(a,k)={1+ka−1ak<a−1(k−(a−1)+1)−1ak≥a−1f(a,k) = \begin{cases} \frac{1+k}{a} - \frac{1}{a} & k < a - 1 \\ \left( k - (a-1) + 1 \right) - \frac{1}{a} & k \ge a - 1 \end{cases} f(a,k)={a1+k​−a1​(k−(a−1)+1)−a1​​k<a−1k≥a−1​

  • 根据单调栈计算出每一种元素作为"最值"的次数，然后将 aaa 排序

G Grid Path

Problem Description

nnn 行 mmm 列的网格，初始在 (1,1)(1,1)(1,1) 位置，可以向左、右、下移动，问合法的路径覆盖区域（不区分经过的顺序）有多少种，结果对 mod\text{mod}mod 取模。

数据范围：1≤n≤1081 \le n \le 10^81≤n≤108，1≤m≤1501 \le m \le 1501≤m≤150，2≤mod≤1092 \le \text{mod} \le 10^92≤mod≤109

Solution

计数 DP、层级 DP、矩阵加速、容斥

显然可以一行一行地进行 DP：

  • 注意到同一行内的移动范围必然是连续的一块
  • 行间的转移必然是有重叠的列才可以转移
  • 转移的时候可以容斥，但是没想到竟然是取反

设：

  • dp[i][l][r]\text{dp}[i][l][r]dp[i][l][r] 表示第 iii 层活动区间在 [l..r][l..r][l..r] 的方案数
  • S[i]S[i]S[i] 表示第 iii 层方案总数
  • 引入辅助变量：C[i][x]=∑l≤xdp[i][l][x]C[i][x] = \sum_{l \le x} \text{dp}[i][l][x]C[i][x]=∑l≤x​dp[i][l][x]，D[i][x]=∑r≥xdp[i][x][r]D[i][x] = \sum_{r \ge x} \text{dp}[i][x][r]D[i][x]=∑r≥x​dp[i][x][r]

踩坑

  • IDEA：关于 DP 推柿子的启发
    • 转移条件正难则反，使用容斥
    • 有时候递推是有对称性的，比如一个前缀、一个后缀
    • 要正确使用换元的方法，不要漏换
    • 一开始推柿子的时候，不要直接朝着答案去设状态，而是从答案的来源进行分类讨论（第 iii 层作为最后一层且处于 [l..r][l..r][l..r] 区间），在求分量的时候，自然会意识到建立新的方便用于答案求解的新状态变量（第 iii 层作为最后一层的方法总和 | F[i][x]=C[i][x]+D[i][m+1−x]F[i][x] = C[i][x] + D[i][m+1-x]F[i][x]=C[i][x]+D[i][m+1−x]）
    • 虽然你可能不必推出所有的细节变量（C[i][x],D[i][x]C[i][x], D[i][x]C[i][x],D[i][x] 等）
    • 但是必须推出方便求解答案的主要变量（S[i],F[i][x],∑SS[i], F[i][x], \sum SS[i],F[i][x],∑S）！
  • IDEA：关于矩阵加速 DP 的启发
    • xTx^TxT 被定义为状态向量，存储所有所需要的状态，可以适当居中状态，两头（0, n+1）塞私货
    • TTT 被定义为转移矩阵，定义了 xxx 各个新的分量与旧的分量的一次函数关系
