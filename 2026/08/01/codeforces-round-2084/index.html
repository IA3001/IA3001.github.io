G2 区间博弈 DP

Problem Description

有一个在序列 ccc 上的博弈，AAA 先手：

  • AAA 选择 iii：c[i] = min(c[i], c[i + 1]) 并删除 c[i+1]c[i + 1]c[i+1]
  • BBB 选择 iii：c[i] = max(c[i], c[i + 1]) 并删除 c[i+1]c[i + 1]c[i+1]

AAA 希望最大化最后剩下的 c[1]c[1]c[1]，定义最终剩下的值为 f(c)f(c)f(c)。

给定长度为 nnn 的排列 ppp（有空缺项），求所有可能中最大的 ppp 的所有子数组的 f()f()f() 之和。

数据范围：1≤n≤5×1051 \le n \le 5 \times 10^51≤n≤5×105

Solution

博弈公式、乘法原理、奇偶二分类、黑白二分类、路径贡献法、Slope Trick、斜率优化 DP

首先一定要推导博弈公式：

  • 使用01二分答案求解博弈答案
  • 假设答案为 mmm，那么 ≥m\ge m≥m 的都设置为 111，其他都是 000
  • 首先考虑奇偶性：
    • 奇数长度最后取 max⁡\maxmax：
      • k=1k = 1k=1：需要 max⁡(c[1],c[m])≥m\max(c[1], c[m]) \ge mmax(c[1],c[m])≥m
      • k=3k = 3k=3：一旦两侧有 111，一定可以避免操作有 111 的位置，然后到达 k−2k-2k−2 状态（true）
      • 否则全 000，那么 BBB 一定可以避免操作两端，达到 000000 状态（false）
    • 偶数长度最后取 min⁡\minmin，必然要求 m≤c[1]m \le c[1]m≤c[1]：
      • k=2k = 2k=2：需要 min⁡(c[1],c[2])≥m\min(c[1], c[2]) \ge mmin(c[1],c[2])≥m
      • k=4k = 4k=4：全 111 那么一定可以达到 111111 状态（true）
      • 否则一旦两侧有 000，那么 BBB 一定会避免操作有 000 的位置，剩下至少一个 000 给 AAA 操作（false）
  • 所以博弈公式为 f(c)=k&1?max⁡(c[1],c[k]):min⁡(c[1],c[k])f(c) = k \& 1 ? \max(c[1], c[k]) : \min(c[1], c[k])f(c)=k&1?max(c[1],c[k]):min(c[1],c[k])

但是为了求解这个 DP 答案，需要公式转化：

ans=∑i≤j[i≡j mod 2]max⁡(pi,pj)+∑i≤j[i≢j mod 2]min⁡(pi,pj)补偿法=∑i≤jmax⁡(pi,pj)+∑i≤j[i≢j mod 2](min⁡(pi,pj)−max⁡(pi,pj))枚举答案法=∑i=1ni2−∑i<j[i≢j mod 2]∣pi−pj∣=n(n+1)(2n+1)6−数轴上两种阵营异色距离之和\begin{aligned} \text{ans} &= \sum_{i \le j} [i \equiv j \bmod 2] \max(p_i, p_j) + \sum_{i \le j} [i \not\equiv j \bmod 2] \min(p_i, p_j) \\ \text{补偿法} &= \sum_{i \le j} \max(p_i, p_j) + \sum_{i \le j} [i \not\equiv j \bmod 2] (\min(p_i, p_j) - \max(p_i, p_j)) \\ \text{枚举答案法} &= \sum_{i=1}^n i^2 - \sum_{i<j} [i \not\equiv j \bmod 2] |p_i - p_j| \\ &= \frac{n(n+1)(2n+1)}{6} - \text{数轴上两种阵营异色距离之和} \end{aligned} ans补偿法枚举答案法​=i≤j∑​[i≡jmod2]max(pi​,pj​)+i≤j∑​[i≡jmod2]min(pi​,pj​)=i≤j∑​max(pi​,pj​)+i≤j∑​[i≡jmod2](min(pi​,pj​)−max(pi​,pj​))=i=1∑n​i2−i<j∑​[i≡jmod2]∣pi​−pj​∣=6n(n+1)(2n+1)​−数轴上两种阵营异色距离之和​

而一个数轴可以看作一个链状树，答案要求的是数轴上 最小 两阵营 距离之和；可以看作是一个树，因此可以考虑边的贡献：一个边被使用了多少次？当然是左右两侧对应的异色点之积。

由于二分类 DP 的补集可预测性，这大大化简了求解 DP 的难度：

  • 设 dp[i][j]\text{dp}[i][j]dp[i][j] 表示数轴上前 iii 个数字染 jjj 个黑点（即染 i−ji-ji−j 个白点）“至少需要的”（因为仅计算前 iii 个边）的最小异色距离之和
  • 溯源法：
    • iii 可染黑色：dp[i][j]←chmindp[i−1][j−1]+j×(⌊n/2⌋−(i−j))+(i−j)×(⌈n/2⌉−j)\text{dp}[i][j] \xleftarrow{\text{chmin}} \text{dp}[i-1][j-1] + j \times (\lfloor n / 2 \rfloor - (i-j)) + (i-j) \times (\lceil n / 2 \rceil - j)dp[i][j]chmin​dp[i−1][j−1]+j×(⌊n/2⌋−(i−j))+(i−j)×(⌈n/2⌉−j)
    • iii 可染白色：dp[i][j]←chmindp[i−1][j]+j×(⌊n/2⌋−(i−j))+(i−j)×(⌈n/2⌉−j)\text{dp}[i][j] \xleftarrow{\text{chmin}} \text{dp}[i-1][j] + j \times (\lfloor n / 2 \rfloor - (i-j)) + (i-j) \times (\lceil n / 2 \rceil - j)dp[i][j]chmin​dp[i−1][j]+j×(⌊n/2⌋−(i−j))+(i−j)×(⌈n/2⌉−j)
  • 贡献法：
    • i+1i+1i+1 可染黑色：dp[i+1][j+1]←chmindp[i][j]+(j+1)×(⌊n/2⌋−((i+1)−(j+1)))+((i+1)−(j+1))×(⌈n/2⌉−(j+1))\text{dp}[i+1][j+1] \xleftarrow{\text{chmin}} \text{dp}[i][j] + (j+1) \times (\lfloor n / 2 \rfloor - ((i+1)-(j+1))) + ((i+1)-(j+1)) \times (\lceil n / 2 \rceil - (j+1))dp[i+1][j+1]chmin​dp[i][j]+(j+1)×(⌊n/2⌋−((i+1)−(j+1)))+((i+1)−(j+1))×(⌈n/2⌉−(j+1))

  • 显然溯源法更简洁
